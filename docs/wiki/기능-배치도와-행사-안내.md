# 배치도와 행사 안내

## 무엇을 하나
- 배치도 탭(2개, `MAP1`/`MAP2`)에서 부스 위치를 보고, 방문 상태·메모 색이 함께 표시됩니다.
- "행사 안내" 탭: 대중교통 오시는 길, 구글맵 약도, 행사 당일 9/12/15시 날씨.

## 왜 이렇게 했나
- 행사장에서 따로 공식 사이트를 찾아보지 않아도 되도록 한곳에 모았습니다.
- 날씨는 API 키가 필요 없는 Open-Meteo를 씁니다. 예보는 대략 행사 2주 전부터 나오므로 그 전엔 안내 문구만 보여줍니다.

## 어떻게 구현했나
- 배치도: `renderMapView()`, `buildPairedColumn()`
- 행사 안내: `renderInfoView()`, `fetchEventWeather()`, `weatherIcon()`
- 행사 정보 상수: `EVENT_DATE`, `VENUE_LAT`, `VENUE_LON`, `VENUE_NAME`, `VENUE_ADDRESS`, `TRANSIT_ROUTES`
  (현재 값은 케모켓 2026-09-20, 東京流通センター. Furst Class 개편 때 바뀔 대상)

## 확인 방법
1. 배치도 탭에서 방문 예정으로 표시한 부스가 노란색인지 확인
2. 행사 안내 탭에서 교통편·지도가 뜨는지, 날씨(또는 안내 문구)가 나오는지 확인
