# 배치도와 행사 안내

## 무엇을 하나
- 배치도 탭: 공식 "일요일 부스 안내" 이미지의 배치를 그대로 옮겨 그린 행사장 지도입니다.
  - 왼쪽 **주성홀**: C구역(C1~C30, 오른쪽 세로줄이 위에서부터 C25~C30). 오른쪽 벽의 분홍 화살표(→ ←)가 출입구입니다.
  - 오른쪽 **그랜드볼룸**: 무대, A구역(A1~A41, A14·A15는 없음: 두 번째 세로줄은 A18·A17·A16 다음 두 칸이 비고 A13~A10), 칸막이 건너 B구역(B1~B34). 위쪽 벽 두 곳의 분홍 화살표(↑↓)가 출입구입니다.
  - 부스 칸을 누르면(키보드는 Tab으로 옮겨 Enter) 부스 탭에서 카드를 누를 때와 **같은 부스 상세 창**이 뜹니다. 마우스를 올리면 부스 번호와 이름이 뜹니다.
  - 메모한 부스는 빨강, 방문 예정은 노랑, 방문 완료는 초록으로 칸이 채워지고, 1·2·3순위는 칸 오른쪽 위의 **숫자 배지**(①빨강 ②보라 ③파랑)로 보입니다(2026-11-21, 그 전에는 칸 바깥 테두리). 방문 예정·완료 칸은 채움색보다 진한 가장자리선이 있어 옆 칸과 구분됩니다. 지도 위에 범례가 있습니다.
  - **우선순위 필터(2026-11-21)**: 구역 버튼 아래 "모든 순위 / ①1순위 / ②2순위 / ③3순위" 버튼. 순위를 고르면 그 순위로 정한 부스만 진하게, 나머지는 흐리게 보이고 "1순위 부스 n곳만 진하게 보여요" 안내가 뜹니다. 그 순위 부스가 없으면 고르는 방법을, 구역 하나만 보는 중에 다른 구역에도 있으면 "n곳은 다른 구역에 있어요"를 알려 줍니다. 구역 필터·검색과 함께 쓸 수 있고, 새로고침해도 고른 순위가 유지됩니다. **💳 선입금 보기에서는 우선순위 버튼 줄과 ①②③ 배지가 나오지 않습니다**(2026-11-21 사용자 요청, 고른 순위는 기억해 두었다가 기본 보기로 돌아오면 다시 적용).
  - **탈의실 칸 없음(2026-11-21)**: 주성홀 위쪽의 남자·여자 탈의실 칸은 사용자 요청으로 지웠습니다. 부스와 상관없는 자리라 지도만 길어졌기 때문입니다. 주성홀 이름표는 홀 위쪽 벽에 붙고, 전체·C구역 보기는 그만큼 위쪽을 잘라 지도가 조금 더 크게 보입니다.
  - **📍 배치도에서 보기(2026-10-18)**: 부스 상세(휴대폰 창·PC 펼침 상세·배치도에서 연 창·선입금 창)의 큰 제목 아래 "📍 배치도에서 보기 (그랜드볼룸 A구역)" 버튼을 누르면, 창을 닫고 배치도 탭으로 넘어가 그 부스가 있는 구역(A/B/C)을 크게 열고 칸을 강조색 굵은 테두리로 세 번 깜빡인 뒤 테두리를 남깁니다.
    휴대폰처럼 배치도가 옆으로 밀리는 화면에서는 그 칸이 화면 가운데 오도록 스크롤합니다. 지도 위에 "📍 [A03] GYM LIGER · 그랜드볼룸 A구역" 안내 줄과 "부스 정보 열기", ✕(강조 끄기) 버튼이 생기고, 다른 탭으로 가면 강조가 꺼집니다.
  - **배치도 검색 강조(2026-10-18)**: 배치도 탭에서 위쪽 검색칸에 글자를 치면 맞는 부스 칸은 강조색 굵은 테두리, 나머지는 흐리게 보이고, 제목 옆에 "검색한 부스 n개를 배치도에 굵은 테두리로 표시했어요"가 뜹니다. 구역 하나만 보는 중에 다른 구역에도 결과가 있으면 "다른 구역에도 검색 결과가 n개 있어요"가 보입니다. 검색 방식은 부스 목록과 같습니다.
  - 두 칸 부스 A11-12, B31-32, C19-20은 붙은 두 칸을 한 도형으로(사이 점선), A37·A38은 모서리로 떨어져 있어 칸마다 따로 그리고 둘 다 같은 부스로 열립니다.
  - 지도 위의 **전체 / A구역 / B구역 / C구역** 버튼으로 한 구역만 크게 볼 수 있습니다. A구역은 무대와 A구역, B구역은 B구역, C구역은 주성홀(탈의실 포함)을 보여줍니다. 고른 버튼은 새로고침해도 유지됩니다.
  - **🗺️ 기본 보기 / 💳 선입금 보기** 버튼: 선입금 보기에서는 선입금 수령 전 노랑, 수령 완료 초록, 선입금이 없는 부스는 흐리게 보이고, 선입금 부스를 누르면 선입금 창이 열립니다([선입금](기능-선입금.md)).
  - 휴대폰처럼 좁은 화면에서는 글자가 너무 작아지지 않게 전체 지도는 폭 960px, 구역 하나는 520px 이상으로 두고 옆으로 밀어서 봅니다.
  - 케모켓 때는 배치도 2개, Furst Class 초기에는 A·B·C 열만 그린 임시 배치도였습니다.

## 왜 이렇게 했나
- 행사장에서 따로 공식 사이트를 찾아보지 않아도 되도록 한곳에 모았습니다.
- **배치도를 이미지 대신 SVG로 그린 이유**: 공식 이미지를 그대로 붙이면 라이트/다크 테마에 맞출 수 없고, 칸마다 메모·방문 상태 색을 입히거나 누를 수 없습니다.
  SVG로 그리면 색을 테마 토큰(`--map-*`)으로 바꿀 수 있고 부스 칸 하나하나가 버튼이 됩니다.
- **우선순위를 테두리 대신 숫자 배지로(2026-11-21)**: 칸 사이 간격이 2px뿐이라 바깥 테두리가 방문 예정(노랑) 채움색·옆 칸 테두리와 붙어 겹쳐 보인다는 사용자 의견. 테두리를 굵게 하면 옆 칸을 더 덮어서, 채움색과 겹치지 않는 모서리 숫자 배지로 바꿨습니다. 숫자가 있어 색을 구분하기 어려운 사람도 순위를 읽을 수 있습니다. 배지는 옆 칸에 가리지 않게 모든 칸을 그린 뒤 맨 위에 그립니다. 위치 찾기·검색 강조의 굵은 테두리는 그대로라 우선순위와 헷갈리지 않습니다.
- **우선순위 필터는 구역 필터와 함께**: 구역 필터는 "어디를 크게 볼지"(지도 자르기), 우선순위 필터는 "어떤 부스를 진하게 볼지"(흐리게 하기)라 서로 다른 일을 해서 같이 켜도 헷갈리지 않습니다. 하나를 고르면 다른 하나가 풀리게 하면 "B구역 1순위"처럼 행사 당일 가장 많이 쓸 조합을 못 써서 함께 쓰게 했습니다. 고른 순위의 부스가 지금 구역 밖에 있으면 안내 줄로 알려 줍니다.
- **부스 칸 기본 모양**: 공식 이미지처럼 칸을 검정·빨강으로 꽉 채우면 메모(빨강) 표시와 구분이 안 돼서, 기본은 구역 색 테두리만 두고 메모·방문 상태일 때만 칸을 채웁니다.
- **구역 버튼을 다른 구역을 숨기는 대신 확대로 만든 이유**: 전체 지도에서는 부스 칸 글자가 작아서, 구역만 남기고 크게 보여주는 편이 행사장에서 찾기 쉽습니다. 다른 구역 칸을 흐리게만 하면 글자 크기가 그대로라 도움이 적습니다.
- **📍 배치도에서 보기를 넣은 이유(2026-10-18 사용자 요청)**: 행사장에서 가장 많이 하는 일이 "이 부스 어디지?"인데, 예전에는 번호를 외워 배치도 탭에서 직접 찾아야 했습니다. C구역은 그랜드볼룸이 아니라 주성홀(다른 홀)이라 버튼에 홀 이름까지 적었습니다.
  구역 선택은 버튼으로 고른 것과 같게 저장되고, 보기 방식(기본/선입금)은 바꾸지 않습니다. 선입금 보기에서 흐리게 보이는 부스도 찾는 부스는 흐리지 않게 합니다.
- **배치도에서 검색해도 탭을 바꾸지 않은 이유**: 예전에는 배치도에서 검색해도 아무 변화가 없었습니다(2026-10-08 점검 9번). 목록으로 넘기기보다 지도 위에서 위치를 바로 보여주는 편이 배치도 탭의 쓰임새에 맞습니다.
- **기준은 일요일 안내**: 사용자가 준 이미지가 "일요일 부스 안내"입니다. 부스 번호·이름은 사이트 데이터(부스 시트)와 99개 모두 같았습니다(2026-10-04 대조). 토요일 배치가 따로 공지되면 다시 확인해야 합니다.
- **FAQ를 사이트에 옮겨 적지 않고 바로가기만 둔 이유(2026-10-27 사용자 요청)**: 질문 내용을 직접 등록하지 말고 바로가기만 만들어 달라는 요청이었습니다. 공식 글이 바뀌어도 사이트를 고칠 필요가 없고, 옮겨 적다 틀릴 일도 없습니다.
  처음엔 테두리 있는 카드로 만들었는데, 사용자가 배치가 예쁘지 않다고 해서 공식 사이트 링크와 같은 모양의 글자 링크로 한 줄에 나란히 두도록 간소화했습니다(같은 날).
- 날씨는 API 키가 필요 없는 Open-Meteo를 씁니다. 예보는 대략 행사 2주 전부터 나오므로 그 전엔 안내 문구만 보여줍니다.

- **공식 X 글을 타임라인 위젯 대신 글 단위로 넣은 이유**: X 공식 타임라인 위젯은 X에 로그인하지 않은 방문자에게 429(요청 제한) 오류로 막혀 보이지 않습니다.
  그래서 글마다 X의 개별 글 임베드(`createTweet`)로 표시합니다. 15초 안에 아무것도 안 뜨면 안내 문구를 보여줍니다.
- **글 목록을 운영자가 고르게 바꾼 이유 (2026-10-05)**: 예전에는 방문자 브라우저가 비공식 API인 FxTwitter에서 글 번호를 받아왔는데,
  X 약관상 비공식 경로로 X 콘텐츠를 가져오는 것이 문제가 될 수 있어 뺐습니다. 후보는 GitHub Actions가 모으고 운영자가 관리 화면에서 반영합니다(사용자 요청, 2026-10-05).

- **타임테이블을 표로 다시 만들지 않고 공식 이미지를 넣은 이유**: 칸이 시간대별로 겹치는 복잡한 표라 다시 그리면 틀릴 위험이 크고, 공식 이미지가 바뀌면 파일만 바꾸면 됩니다.
  이미지 자체가 흰 바탕이라 다크 테마에서도 잘 보여 테마별로 따로 손대지 않았고, 휴대폰에서는 글자가 작아서 원래 크기 확대 기능을 넣었습니다.
  행사 안내 탭과 따로 둔 이유는 행사장에서 시간표를 자주 열어 볼 텐데, 안내 탭 안에 있으면 약도·공식 글 사이에서 찾아 내려가야 하기 때문입니다(사용자 요청, 2026-10-13).
  요일을 버튼으로 나눈 이유는 두 장을 세로로 이어 붙이면 탭이 너무 길어져서입니다.
- **단체촬영 일정을 시트에서 실시간으로 읽지 않고 파일로 넣은 이유 (2026-11-26)**: 브라우저에서 구글 시트를 직접 읽으려면 시트 공개 설정·CORS 문제가 있고, 사이트의 보안 설정(CSP `connect-src`)도 넓혀야 합니다.
  또 행사장 회선이 느리거나 끊겨도 보여야 해서 사이트 파일 안에 둡니다. 대신 시트가 바뀌면 `timetable/group-photos.js`만 고치면 되도록 데이터를 코드와 분리했습니다.
  `data/` 폴더는 배포에서 빠지므로(`.assetsignore`) 배포되는 `timetable/` 폴더에 둡니다. 새 탭을 만들지 않고 행사 시간표 탭 안에 넣은 이유는 탭 줄이 이미 길고, 공식 시간표와 같은 "언제 무엇을" 정보라서입니다.
