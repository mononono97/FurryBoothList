# 배치도와 행사 안내

## 무엇을 하나
- 배치도 탭: 공식 "일요일 부스 안내" 이미지의 배치를 그대로 옮겨 그린 행사장 지도입니다.
  - 왼쪽 **주성홀**: 남자·여자 탈의실과 C구역(C1~C28). 오른쪽 벽의 분홍 화살표(→ ←)가 출입구입니다.
  - 오른쪽 **그랜드볼룸**: 무대, A구역(A1~A41), 칸막이 건너 B구역(B1~B34). 위쪽 벽 두 곳의 분홍 화살표(↑↓)가 출입구입니다.
  - 부스 칸을 누르면(키보드는 Tab으로 옮겨 Enter) 부스 탭에서 카드를 누를 때와 **같은 부스 상세 창**이 뜹니다. 마우스를 올리면 부스 번호와 이름이 뜹니다.
  - 메모한 부스는 빨강, 방문 예정은 노랑, 방문 완료는 초록으로 칸이 채워지고, 1·2·3순위는 칸 바깥 테두리(빨강·보라·파랑)로 보입니다. 지도 위에 범례가 있습니다.
  - 두 칸 부스 A11-12, B31-32, C19-20은 붙은 두 칸을 한 도형으로(사이 점선), A37·A38은 모서리로 떨어져 있어 칸마다 따로 그리고 둘 다 같은 부스로 열립니다.
  - 지도 위의 **전체 / A구역 / B구역 / C구역** 버튼으로 한 구역만 크게 볼 수 있습니다. A구역은 무대와 A구역, B구역은 B구역, C구역은 주성홀(탈의실 포함)을 보여줍니다. 고른 버튼은 새로고침해도 유지됩니다.
  - **🗺️ 기본 보기 / 💳 선입금 보기** 버튼: 선입금 보기에서는 선입금 수령 전 노랑, 수령 완료 초록, 선입금이 없는 부스는 흐리게 보이고, 선입금 부스를 누르면 선입금 창이 열립니다([선입금](기능-선입금.md)).
  - 휴대폰처럼 좁은 화면에서는 글자가 너무 작아지지 않게 전체 지도는 폭 960px, 구역 하나는 520px 이상으로 두고 옆으로 밀어서 봅니다.
  - 케모켓 때는 배치도 2개, Furst Class 초기에는 A·B·C 열만 그린 임시 배치도였습니다.

## 왜 이렇게 했나
- 행사장에서 따로 공식 사이트를 찾아보지 않아도 되도록 한곳에 모았습니다.
- **배치도를 이미지 대신 SVG로 그린 이유**: 공식 이미지를 그대로 붙이면 라이트/다크 테마에 맞출 수 없고, 칸마다 메모·방문 상태 색을 입히거나 누를 수 없습니다.
  SVG로 그리면 색을 테마 토큰(`--map-*`)으로 바꿀 수 있고 부스 칸 하나하나가 버튼이 됩니다.
- **부스 칸 기본 모양**: 공식 이미지처럼 칸을 검정·빨강으로 꽉 채우면 메모(빨강) 표시와 구분이 안 돼서, 기본은 구역 색 테두리만 두고 메모·방문 상태일 때만 칸을 채웁니다.
- **구역 버튼을 다른 구역을 숨기는 대신 확대로 만든 이유**: 전체 지도에서는 부스 칸 글자가 작아서, 구역만 남기고 크게 보여주는 편이 행사장에서 찾기 쉽습니다. 다른 구역 칸을 흐리게만 하면 글자 크기가 그대로라 도움이 적습니다.
- **기준은 일요일 안내**: 사용자가 준 이미지가 "일요일 부스 안내"입니다. 부스 번호·이름은 사이트 데이터(부스 시트)와 99개 모두 같았습니다(2026-10-04 대조). 토요일 배치가 따로 공지되면 다시 확인해야 합니다.
- 날씨는 API 키가 필요 없는 Open-Meteo를 씁니다. 예보는 대략 행사 2주 전부터 나오므로 그 전엔 안내 문구만 보여줍니다.

- **공식 X 글을 타임라인 위젯 대신 글 단위로 넣은 이유**: X 공식 타임라인 위젯은 X에 로그인하지 않은 방문자에게 429(요청 제한) 오류로 막혀 보이지 않습니다.
  그래서 글마다 X의 개별 글 임베드(`createTweet`)로 표시합니다. 15초 안에 아무것도 안 뜨면 안내 문구를 보여줍니다.
- **글 목록을 운영자가 고르게 바꾼 이유 (2026-10-05)**: 예전에는 방문자 브라우저가 비공식 API인 FxTwitter에서 글 번호를 받아왔는데,
  X 약관상 비공식 경로로 X 콘텐츠를 가져오는 것이 문제가 될 수 있어 뺐습니다. 후보는 GitHub Actions가 모으고 운영자가 관리 화면에서 반영합니다(사용자 요청, 2026-10-05).

## 어떻게 구현했나
- 배치도: `renderMapView()`(범례 + SVG, 클릭·Enter 처리), `buildMapSvg()`(벽·탈의실·무대·구역·출입구·부스 칸), `MAP_SLOTS`(부스 번호 → 칸 좌표, 전체 `viewBox="100 200 1720 663"` 기준),
  `mapDoorArrows()`, `mapHallLabel()`(홀 이름표, 그린 뒤 글자 폭에 맞춰 바탕 크기 조정)
  - 부스 칸 크기: `MAP_W`=40, `MAP_H`=32(2026-10-04 26에서 키움), `MAP_STEP`=34. 가운데 두 줄은 높이 36, 간격 40
  - 구역 필터: `mapZone`("ALL"/"A"/"B"/"C"), `setMapZone()`, `MAP_ZONE_VIEWBOX`(구역별 SVG viewBox). 구역을 고르면 viewBox 를 그 구역으로 바꾸고 `clipPath`로 바깥을 잘라 옆 구역이 비치지 않게 함.
    보기 방식: `mapMode`("basic"/"preorder"), `setMapMode()`, 저장 키 `furstclass-map-mode`, 부스 칸 클릭은 `openMapBooth()`.
    저장 키 `furstclass-map-zone`. 버튼은 메모 탭 방문 필터와 같은 모양(`.visit-filter.map-zone-filter`), 문구는 `mapZoneAll`, `mapZoneA~C`
  - 부스는 `BOOTHS`의 `block` + `nums`로 칸을 찾습니다(예: `A37-38` → `A37`, `A38`). 데이터에 없는 칸은 회색 점선 빈 칸으로 그리고 누를 수 없습니다.
  - 스타일: `.venue-map`, `.map-booth`(상태 클래스 `has-note`, `visit-planned`, `visit-visited`, `priority-1~3`), `.map-legend`
  - 색 토큰(라이트·다크 두 블록 모두): `--map-wall`, `--map-room-line`, `--map-zone-a`, `--map-zone-bc`, `--map-booth-a`, `--map-booth-bc`, `--map-stage(-fg)`, `--map-arrow`,
    `--map-pill-dark`, `--map-pill-fg`, `--map-planned(-fg)`, `--map-visited(-fg)`, `--map-prio-1~3`
  - 글자(홀 이름·탈의실·무대·구역·범례)는 i18n 키 `mapTitle`, `mapHall*`, `mapMaleRoom`, `mapFemaleRoom`, `mapStage`, `mapZone*`, `mapLegend*`
- 행사 안내: `renderInfoView()`, `fetchEventWeather()`, `weatherIcon()`
- 행사 정보 상수: `EVENT_DATES`, `EVENT_PERIOD_TEXT`, `VENUE_LAT`, `VENUE_LON`, `VENUE_NAME`, `VENUE_ADDRESS`, `VENUE_MAP_QUERY`, `OFFICIAL_SITE_URL`, `WEATHER_HOURS`
- 공식 X 글: `OFFICIAL_X_HANDLE`, `fetchOfficialPostIds()`(`loadBoothPostsDoc()`로 Firestore `boothPosts/main`의 `official` 글 id를 최신순으로,
  없으면 `OFFICIAL_POST_FALLBACK_IDS`), `loadOfficialFeed()`(글마다 `twttr.widgets.createTweet`, 한 번에 `OFFICIAL_POST_BATCH`=4개, 15초 안내).
  후보 수집과 관리 화면은 [부스 상품 정보](기능-부스-상품-정보.md) 참고. 8/21 게스트 관련 글은 수집 스크립트의 `OFFICIAL_SKIP_IDS`로 후보에서도 뺌.
  CSP `connect-src`에서 `https://api.fxtwitter.com`을 뺌. 스타일은 `.official-feed`

## 확인 방법
1. 배치도 탭이 공식 일요일 부스 안내 이미지와 같은 배치인지 확인(주성홀·C구역, 그랜드볼룸·무대·A·B구역, 출입구 화살표 3곳)
   - 부스 칸을 누르면 부스 탭 카드와 같은 상세 창이 뜨는지, A37과 A38 칸 둘 다 Whitefangwolves 창이 뜨는지 확인
   - 상세 창에서 방문 예정을 누르고 닫으면 그 칸이 노란색이 되는지, 메모·방문 완료·우선순위도 범례대로 보이는지 확인
   - 설정에서 라이트/다크를 바꿔도 지도가 잘 보이는지, 휴대폰에서는 옆으로 밀어서 볼 수 있는지 확인
   - A구역·B구역·C구역 버튼을 누르면 그 구역만 크게 보이고, 전체를 누르면 돌아오는지, 새로고침해도 고른 구역이 유지되는지 확인
2. 행사 안내 탭에서 지도가 뜨는지, 날씨(또는 안내 문구)가 나오는지 확인
3. X에 로그인하지 않은 브라우저(시크릿 창)에서도 공식 X 글이 스크롤 구역에 뜨는지, 아래 X 링크가 있는지 확인
4. 관리 화면 "행사 안내 글"에서 반영한 글만 최신순으로 보이는지, 개발자 도구 Network 탭에 `api.fxtwitter.com` 요청이 없는지 확인
