# 배치도와 행사 안내

## 무엇을 하나
- 배치도 탭(케모켓 때 2개. Furst Class는 실제 배치도를 받기 전까지 임시 배치도 1개)에서 부스 위치를 보고, 방문 상태·메모 색이 함께 표시됩니다.
- "행사 안내" 탭: 일정, 장소, 구글맵 약도, 행사 당일 날씨.
  - Furst Class: 2026-11-28~29, 엔포드 호텔 청주(충청북도 청주시 청원구 충청대로 114), 11/14/17시 날씨.
    교통편은 공식 사이트에 정리된 내용이 없어 공식 사이트 링크로 대신합니다.
  - 공식 X 계정(@FURSTCLASS_KR)의 2026-06-16 이후 글(리트윗·답글·숨김 글 제외)을 정해진 높이(PC 520px, 모바일 420px)의 스크롤 구역에 보여주고, 아래에 X 계정 링크를 항상 둡니다.
    처음엔 4개만 그리고 구역 안에서 아래로 스크롤하면 이어서 그립니다.
  - 케모켓 때: 東京流通センター, 대중교통 오시는 길, 9/12/15시 날씨.

## 왜 이렇게 했나
- 행사장에서 따로 공식 사이트를 찾아보지 않아도 되도록 한곳에 모았습니다.
- 날씨는 API 키가 필요 없는 Open-Meteo를 씁니다. 예보는 대략 행사 2주 전부터 나오므로 그 전엔 안내 문구만 보여줍니다.

- **공식 X 글을 타임라인 위젯 대신 글 단위로 넣은 이유**: X 공식 타임라인 위젯은 X에 로그인하지 않은 방문자에게 429(요청 제한) 오류로 막혀 보이지 않습니다.
  그래서 공개 API인 FxTwitter에서 글 번호만 받아오고(페이지를 넘겨 가며 최대 8페이지), 글마다 X의 개별 글 임베드(`createTweet`)로 표시합니다.
  FxTwitter가 실패하면 미리 적어둔 글 번호로 대신하고, 15초 안에 아무것도 안 뜨면 안내 문구를 보여줍니다.

## 어떻게 구현했나
- 배치도: `renderMapView()`, `buildPairedColumn()`
- 행사 안내: `renderInfoView()`, `fetchEventWeather()`, `weatherIcon()`
- 행사 정보 상수: `EVENT_DATES`, `EVENT_PERIOD_TEXT`, `VENUE_LAT`, `VENUE_LON`, `VENUE_NAME`, `VENUE_ADDRESS`, `VENUE_MAP_QUERY`, `OFFICIAL_SITE_URL`, `WEATHER_HOURS`
- 공식 X 글: `OFFICIAL_X_HANDLE`, `fetchOfficialPostIds()`(`https://api.fxtwitter.com/2/profile/FURSTCLASS_KR/statuses`를 `OFFICIAL_POST_SINCE` 이전 글이 나올 때까지,
  최대 `OFFICIAL_POST_MAX_PAGES`=8페이지), `loadOfficialFeed()`(글마다 `twttr.widgets.createTweet`, 한 번에 `OFFICIAL_POST_BATCH`=4개, 15초 안내),
  숨길 글은 `OFFICIAL_POST_HIDDEN_IDS`(2026-10-02 사용자 요청: 8/21 게스트 관련 글), 실패 시 `OFFICIAL_POST_FALLBACK_IDS`.
  CSP `connect-src`에 `https://api.fxtwitter.com` 추가. 스타일은 `.official-feed`
- 배치도는 칸 단위 CSS grid. 두 칸 부스는 `.map-cell.double` 하나가 두 칸에 걸침
