# 부스원과 부스컷 (Furst Class)

Furst Class 부스 시트를 사이트 데이터로 바꾸고, 부스마다 여러 명의 부스원과 부스컷을 보여주는 기능입니다.
[Furst Class 개편](작업-Furst-Class-개편.md) 작업의 첫 단계로 2026-10-02에 만들었습니다.

## 무엇을 하나
- 부스 열 탭이 시트 기준 **A(일반 41칸), B(성인 34칸), C(성인 28칸)** 로 바뀌었습니다. 총 103칸.
- **두 칸 부스**: 같은 열에서 번호가 이어지고 부스 이름이 같은 부스는 한 부스로 합쳐 `A37-38` 처럼 표시합니다.
  지금은 A11-12(콩자반 김자반), A37-38(Whitefangwolves), B31-32(퍼리다이소 ~카지노점~), C19-20(작전명: 에이전트 버니) 4개라서
  부스 수는 A 39개, B 33개, C 27개, 총 99개입니다. 두 칸의 리더·부스원은 한 목록으로 합쳐집니다(앞 칸 리더가 맨 위).
  배치도에서는 두 칸을 이어 붙인 하나의 도형(칸마다 번호, 사이에 점선)으로 그립니다.
- 성인 부스 카드에는 부스 번호 옆에 빨간 `18+` 표시가, 팝오버·모달 머리글에는 🔞 표시가 붙습니다.
- 카드 아래 이름은 "리더 이름 외 N명" 으로 표시됩니다.
- 부스 카드를 누르면 팝오버 위쪽에 **부스컷**과 **부스원 목록**이 나옵니다. 부스 리더가 맨 위에 오고, "리더/부스원" 같은 구분 표시는 하지 않습니다.
  - X 아이디가 있는 사람: 프로필 사진(또는 이름 첫 글자)과 `@아이디` 를 누르면 X 프로필이 새 탭으로 열립니다.
  - X 아이디가 없는 사람: 이름과 "X 계정 없음" 만 보입니다.
  - 부스컷 이미지를 누르면 화면 전체 크기로 크게 보이고, 다시 누르거나 Esc를 누르면 닫힙니다.
  - 부스컷 파일이 아직 없으면 "부스컷 준비 중"(시트 I열이 O) 또는 "부스컷 미제출"(I열이 비어 있음) 이 보입니다.
- 검색창은 부스명·부스 번호뿐 아니라 **모든 부스원의 이름과 X 아이디**로도 찾습니다.
- 배치도 탭에서 부스를 눌렀을 때 뜨는 모달에도 같은 부스컷·부스원 목록이 나옵니다.

## 왜 이렇게 했나
- **데이터는 계속 index.html 안에 넣었습니다.** 시트를 실시간으로 읽어오면 오프라인 열람(서비스 워커)이 깨지고
  구글 시트 공개 설정에 의존하게 되어, 시트 CSV를 저장소에 두고 스크립트로 변환하는 방식을 택했습니다.
- **리더·부스원 칸 파싱 규칙** (`tools/build_booths.py` 의 `parse_person()`)
  - `닉네임 / @아이디`, `닉네임 @아이디`, `닉네임(@아이디)`, `@ 아이디`(공백 포함) 모두 같은 형태로 정리합니다.
  - `@아이디` 만 있으면 아이디를 이름으로도 씁니다.
  - `이데아/ 이데아/ @ideatami` 처럼 이름이 반복되면 하나로 합칩니다.
  - 리더와 같은 사람이 부스원 칸에 또 적힌 경우(예: `엘븐/@elvendays` + `엘븐`)는 한 번만 보여줍니다.
  - `없음`, `추후 추가하겠습니다.` 같은 칸은 빈 칸으로 취급합니다.
  - 자동으로 판단하기 애매한 4개 칸은 `OVERRIDES` 에 직접 적었습니다:
    `해태/@Ringo@2ALS`(→ ringo2ALS, 작가 아이디 확인함), `영원양 /@young_wonyang`(→ youngwonyang, 시트의 아이디는 X에 없는 계정), `@타패/tappe124`(→ tappe124),
    `콩조림/kongzorim`(@ 없는 아이디), `凛＠STUDIO雄虎凛/@GTDignified`(전각 ＠는 이름의 일부).
  - 시트에 X 아이디 없이 이름만 적혀 있던 22명은 사용자가 알려준 아이디를 `HANDLE_FILL`(부스 번호 + 이름 → 아이디)에 적어 채웁니다(2026-10-02).
  - A03(Raigo·藤堂雷悟), A04(Wald·逢魔牙ワルト), A05(Trad Monmon·虎渡悶々)는 이름이 비슷하지만 사용자 확인으로 각각 별개의 사람이라 따로 표시합니다.
- **케모켓 데이터 정리** (2026-10-02, 케모켓 행사가 끝나 완전히 지우기로 결정)
  - localStorage 키를 모두 `furstclass-*` 로 바꿨습니다(메모·방문상태·예산·우선순위·마지막 탭·정렬·언어).
    접속할 때 브라우저에 남아 있던 `kemoket-*` 키는 지웁니다.
  - Firestore: `users/{uid}` 문서의 `furstclass` 필드에 저장하고, 동기화할 때 문서 전체를 덮어써서
    케모켓 때 문서 최상위에 있던 `notes` 등의 필드는 처음 동기화할 때 지워집니다.
  - `avatars/` 에서 케모켓 작가 프로필 사진 629개를 지우고, Furst Class 부스원과 겹치는 9개만 남겼습니다.
  - 케모켓용 사이트 마지막 상태는 `kemoket` 브랜치(커밋 `137e0ae`)에 그대로 보관합니다.
- **두 칸 부스 판단 기준**: 시트에 두 줄로 따로 적혀 있지만 같은 부스이므로, 이름이 같고 번호가 연속인 경우만 합칩니다.
  엘븐스토어 1(A23)·엘븐스토어2(B34)처럼 번호가 떨어진 부스는 따로 둡니다.
  합치기 전에 `A37` 같은 칸 번호로 저장된 메모·방문상태·우선순위·예산은 접속할 때(그리고 클라우드에서 받아올 때) `A37-38` 로 옮깁니다.
- **예산 단위**를 엔(¥)에서 원(₩)으로 바꾸고, 입력 단위를 1,000원으로 했습니다.
- **배치도**: 실제 배치도를 아직 받지 못해 A·B·C 열을 단순한 두 줄 구조로 그린 임시 배치도 1장으로 합쳤습니다(화면에 "실제 배치와 다를 수 있음" 표시).
- **행사 안내**: 공식 사이트 기준 일정(2026-11-28~29), 장소(엔포드 호텔 청주, 충청북도 청주시 청원구 충청대로 114), 지도, 청주 날씨로 바꿨습니다.
  교통편은 공식 사이트에 정리된 내용이 없어 지어내지 않고 공식 사이트 링크로 대신했습니다.
- **기본 언어**: 처음 방문한 사람은 브라우저 언어(한국어/일본어, 그 외 영어)를 따라갑니다. 언어를 직접 고른 적이 있으면 그 설정이 유지됩니다.

## 어떻게 구현했나
- 데이터
  - 원본: `data/furstclass_booths.csv` (시트 그대로)
  - 변환: `python3 tools/build_booths.py` → `index.html` 의 `const BOOTHS = ...;` 한 줄을 다시 씀
  - 확인만: `python3 tools/build_booths.py --check` (부스별 파싱 결과 출력, 파일은 안 바꿈)
  - 부스 데이터 형식: `{ id: "A10", block: "A", num: "10", nums: ["10"], adult: false, name, rep, twitter, cut: true, members: [{ name, twitter, role: "leader" | "member" }] }`
  - 두 칸 부스: `merge_double_booths()` 가 `{ id: "A37-38", num: "37-38", nums: ["37", "38"], ... }` 로 합침
  - `data/x-handles-missing-avatars.txt`: `avatars/` 에 프로필 사진이 아직 없는 X 아이디 목록(스크립트가 같이 갱신)
- 화면 (`index.html`)
  - `buildBoothCut()`, `boothCutUrl()`, `openCutLightbox()`, `closeCutLightbox()`: 부스컷
  - `buildMemberList()`, `openXProfile()`: 부스원 목록
  - `boothSubLine()`, `boothRepText()`: 머리글 두 번째 줄, 카드의 "외 N명"
  - `makePopover()` 내용은 `.pop-body` 안에 들어가고, `positionPopover()` 가 화면 공간에 맞게 최대 높이를 정해서 길면 안쪽에서 스크롤됩니다.
  - `STORAGE_PREFIX = "furstclass"`, `pushToCloud()`, `pullAndMergeFromCloud()`: 저장 키와 클라우드 저장
  - `MERGED_BOOTH_ALIASES`, `migrateMergedBoothIds()`: 두 칸 부스의 예전 칸 번호 저장값 이전
  - `buildPairedColumn()`: 배치도를 칸 단위 CSS grid 로 그림. 두 칸 부스는 `.map-cell.double` 하나가 두 칸에 걸침(4줄마다 통로)
  - `EVENT_DATES`, `VENUE_*`, `renderInfoView()`: 행사 안내
- 부스컷 파일: `booth-cuts/부스번호.jpg` (예: `booth-cuts/A01.jpg`). 자세한 규칙은 `booth-cuts/README.md`.
- 서비스 워커(`sw.js`): `booth-cuts/` 도 아바타처럼 캐시 우선으로 저장, 404 응답은 캐시하지 않음, 캐시 이름 `furstclass-cache-v1`.

## 시트가 바뀌었을 때
1. 구글 시트에서 파일 → 다운로드 → CSV 로 받아 `data/furstclass_booths.csv` 를 덮어씁니다.
2. `python3 tools/build_booths.py --check` 로 이름/아이디가 제대로 나뉘었는지 확인합니다. 이상한 칸은 `OVERRIDES` 에 추가합니다.
3. `python3 tools/build_booths.py` 를 실행하고 커밋합니다.

## 프로필 사진 받기
- `python3 tools/fetch_avatars.py` 를 PC에서 실행하면 사진이 없는 부스원의 X 프로필 사진을 `avatars/아이디.jpg` 로 받습니다.
- 유료 API·API 키 없이, X 임베드 위젯이 쓰는 공개 페이지에서 사진 주소를 찾습니다. 못 찾으면 Playwright가 설치된 경우에만 x.com 프로필 페이지를 헤드리스 브라우저로 열어 찾습니다.
- 요청 사이에 2초씩 쉬고(`--delay` 로 조절), 이미 있는 사진은 건너뜁니다(`--force` 로 다시 받기).
- 받은 뒤 `python3 tools/build_booths.py` 를 실행하면 사진 없는 아이디 목록이 갱신됩니다.

## 부스컷 이미지를 받았을 때
1. 파일 이름을 부스 번호로 바꿉니다(`A01.jpg`, 대문자 + 두 자리 숫자 + 소문자 `.jpg`). 두 칸 부스는 `A37-38.jpg`.
2. `booth-cuts/` 폴더에 넣고 커밋합니다.
3. 이미 올린 이미지를 같은 이름으로 교체했다면 `sw.js` 의 `CACHE_VERSION` 을 올립니다.

## 확인 방법
1. A/B/C 탭에 각각 39/33/27개 부스가 나오는지, A11-12 카드가 하나로 나오는지, B·C 카드에 `18+` 가 붙는지 확인

3. A13(코치문고)을 눌러 X 아이디 없는 부스원(테이릿, 림)이 "X 계정 없음" 으로 나오는지 확인
