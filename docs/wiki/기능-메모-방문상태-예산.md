# 메모·방문 상태·예산

## 무엇을 하나
- 부스마다 개인 메모를 남길 수 있습니다(최대 1000자, 예시 문구 "동인지 한권, 아크릴 키링 하나").
- 방문 예정(노란색) / 방문 완료(초록색)를 토글할 수 있고, 부스 카드와 배치도에 색으로 표시됩니다.
- 상태 없이 메모만 있는 부스는 클레이(주황)색으로 구분합니다.
- 부스별 예산(엔)을 입력하면 메모 탭에서 총합이 보입니다.
- 메모 탭: 메모·상태가 있는 부스만 모아 보고, 전체/방문 예정/방문 완료로 필터링합니다.

## 왜 이렇게 했나
- 행사장에서 동선을 짜고 지출을 관리하려는 용도입니다.
- 메모만 있는 부스가 방문 예정과 같은 노란색 계열이라 헷갈려서 색을 따로 분리했습니다.
- 데이터는 기본적으로 브라우저에만 저장됩니다. 기기 간에 옮기려면 처음엔 JSON
  내보내기/가져오기를 썼고, 지금은 [Google 로그인 동기화](기능-Google-로그인-동기화.md)로 대체했습니다.

## 어떻게 구현했나
- 메모: `NOTES_KEY`, `loadNotes/saveNotes/getNote/setNote`, `updateNoteVisuals()`, `MAX_NOTE_LENGTH`
- 방문 상태: `VISIT_KEY`, `getVisitStatus/setVisitStatus`, `updateVisitVisuals()`
- 예산: `BUDGET_KEY`, `getBudget/setBudget/getTotalBudget`, `formatYen()`, `updateBudgetTotalDisplay()`
- 메모 탭 필터: `notesVisitFilter` ("all" | "planned" | "visited")

## 확인 방법
1. 부스 팝오버에서 메모 입력 → 카드 색이 주황으로 바뀌는지 확인
2. 방문 예정/완료 토글 → 노랑/초록으로 바뀌고 배치도에도 반영되는지 확인
3. 예산 입력 후 메모 탭 상단 합계가 맞는지 확인
4. 새로고침 후 값이 남아 있는지 확인
