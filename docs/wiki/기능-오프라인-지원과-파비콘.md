# 오프라인 지원과 파비콘

## 무엇을 하나
- 한 번 접속한 뒤에는 인터넷이 끊겨도 사이트를 볼 수 있습니다(행사장 통신 불안정 대비).
- 브라우저 탭에 파비콘이 보입니다.

## 왜 이렇게 했나
- 페이지는 **네트워크 우선**: 온라인이면 항상 최신, 오프라인이면 캐시 사용
- 아바타 이미지는 **캐시 우선**: 한 번 본 이미지는 오프라인에서도 계속 보임
- 파비콘을 `favicon.ico`로 저장했는데 실제로는 PNG라 브라우저가 표시하지 못해 `favicon.png`로 바꿨습니다.

## 어떻게 구현했나
- `sw.js`: 캐시 이름 `furstclass-cache-v3` (`CACHE_VERSION`, 케모켓 때는 `kemoket-cache-v1`).
  부스컷(`booth-cuts/`)도 아바타처럼 캐시 우선, 404 응답은 캐시하지 않음. 캐시 구조를 바꾸면 버전을 올려 이전 캐시를 지웁니다.
- CSP에 `worker-src 'self'` 추가

## 확인 방법
1. 사이트 접속 → 개발자 도구(F12) → Application → Service Workers에서 등록 확인
2. Network 탭에서 Offline 체크 후 새로고침 → 사이트가 뜨는지 확인
