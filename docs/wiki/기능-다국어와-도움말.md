# 다국어와 도움말

## 무엇을 하나
- UI 문구를 한국어·영어·일본어로 전환할 수 있습니다. 서클명·대표자명은 번역하지 않습니다.
- 처음 방문하면 브라우저 언어를 따릅니다(한국어/일본어, 그 외 영어). 언어를 직접 고르면 그 설정이 유지됩니다.
- 도움말 모달에는 사이트 소개·AI 사용 안내(공식 사이트 링크)와 크레딧(X @Chung_Hwani)만 둡니다. 기능별 사용법은 사용법 설명서로 옮겼습니다(2026-10-05).
- 도움말 모달 맨 위에 "📖 사용법 설명서 보기" 버튼이 있어, 누르면 사용법 설명서 PDF(Google 드라이브)가 새 탭으로 열립니다. 설명서는 한국어·영어·일본어판이 있고, 사이트 언어(KO/EN/JP)에 맞는 판이 열립니다(2026-10-27).
- 처음 방문하면 도움말 모달이 자동으로 한 번 열립니다([첫 방문 안내와 성인 부스 안내](기능-첫-방문-안내와-성인-부스-안내.md)).
- 하단에는 데이터 출처 링크만 둡니다.
- 설명서 파일은 프로젝트 공유 폴더 `guide/`에서 만듭니다(한국어 `Furst-Class-부스목록-사용법.pdf`, 영어 `Furst-Class-Booth-List-Guide-EN.pdf`, 일본어 `Furst-Class-Booth-List-Guide-JP.pdf`, 23장). 만드는 스크립트와 언어별 문구는 `guide/_source/`(`shoot.js`, `slides.js`, `texts.js`)에 있습니다.

## 왜 이렇게 했나
- 일본 행사에 한국·일본·해외 방문자가 함께 써서 3개 언어로 시작했습니다.
- 하단 안내 문구는 도움말과 중복되고 실제 동작과 어긋나 정리했습니다.
- 영어·일본어 화면에서 한국어 설명서만 열리면 읽기 어려워서, 2026-10-27 사용자 요청으로 영어·일본어판을 만들고 언어에 맞춰 열리게 했습니다. 버튼 하나만 두어 도움말이 복잡해지지 않게 했고, 다른 언어판이 필요하면 설정에서 언어를 바꾸면 됩니다.
- 그림이 있는 사용법 설명서가 생겨 도움말의 기능 설명(로그인 동기화, 오프라인, 검색, 메모, 선입금, 배치도 색, 우선순위, 언어, 테마)은 지우고 설명서 버튼으로 대신했습니다. 설명이 두 곳에 있으면 기능이 바뀔 때 한쪽만 고쳐져 어긋나기 쉽기 때문입니다.

## 어떻게 구현했나
- 번역 함수 `t(key, params)`, 언어 전환 `setLang()`, 고정 문구 반영 `applyStaticTexts()`, 저장 키 `furstclass-lang`
- 도움말: `openHelpModal()`
- 설명서 버튼: 링크는 언어별 `HELP_GUIDE_URL` 객체(`ko`·`en`·`jp`, 없으면 `ko`), `openHelpModal()`에서 `currentLang`으로 고릅니다. 문구는 `helpGuideBtn`, 스타일은 `.help-guide-btn`(선입금 창 버튼과 같은 모양). 영어·일본어판이 생겨 버튼 문구의 "Korean/韓国語" 표시는 뺐습니다.
- 설명서를 고쳐 다시 올릴 때는 Google 드라이브에서 기존 파일에 "새 버전 업로드"를 하면 링크가 그대로라 사이트를 고칠 필요가 없습니다.
- 새 문구를 추가할 때는 KO/EN/JP 세 언어를 모두 채웁니다.

## 확인 방법
1. 설정 메뉴에서 언어를 바꿔 탭·버튼·도움말 문구가 모두 바뀌는지 확인
2. 새로고침 후 언어가 유지되는지 확인
3. 설정 메뉴 → 도움말에서 "📖 사용법 설명서 보기" 버튼을 눌러 Google 드라이브 설명서가 새 탭으로 열리는지 확인. 언어를 KO·EN·JP로 바꿔 가며 도움말을 다시 열어 각각 한국어·영어·일본어판이 열리는지, EN·JP 버튼 문구에 "Korean/韓国語"가 없는지 확인
