# 우선순위 정렬

## 무엇을 하나
- 부스마다 우선순위 1·2·3을 지정할 수 있습니다(1이 가장 높음).
- 정렬 버튼을 켜면 부스 목록이 1→2→3→미지정 순으로 정렬되고, 새로고침해도 유지됩니다.

## 왜 이렇게 했나
- 방문 예정만으로는 "꼭 가야 하는 곳"과 "시간 나면 갈 곳"을 구분하기 어려워 추가했습니다.
- 배경색은 이미 방문 상태·메모 표시에 쓰고 있어서, 우선순위는 카드 테두리(outline)로 표시합니다.

## 어떻게 구현했나
- 값: `PRIORITY_KEY`(`furstclass-priority`, 케모켓 때는 `kemoket-priority`), `loadPriority/savePriority/getPriority/setPriority`, `updatePriorityVisuals()`
- 정렬: `SORT_PRIORITY_KEY`(`furstclass-sort-priority`), `toggleSortByPriority()`
- 로그인 시 Firestore 동기화 대상에 포함

## 확인 방법
1. 몇 개 부스에 우선순위 1, 2, 3 지정 → 테두리 표시 확인
2. 정렬 켜기 → 순서 확인, 새로고침 후에도 유지 확인
3. 정렬 끄기 → 원래 부스 번호 순으로 복귀 확인
