# Furst Class 개편

> 상태: **진행 중** (2026-10-02 시작). 구현은 별도 작업 스레드에서 진행하며, 끝나면 이 문서에 결과를 정리합니다.

## 목표
기존 케모켓(2026-09-20, 도쿄) 부스 목록 사이트를 2026년 11월 말 한국에서 열리는
퍼리 행사 **Furst Class**(https://furst-class.com/)용으로 개편합니다.

## 받은 자료 (2026-10-02)
부스 목록 Google 스프레드시트. 열 구성은 다음과 같습니다.

| 열 | 내용 | 사용 |
|---|---|---|
| A | 부스 번호 | 사용 |
| B | 일반/성인 부스 구분 | 사용 |
| C | 부스 이름 | 사용 |
| D | 부스 리더 | 사용 |
| E, F | 부스원 | 사용 |
| G, H | (제외) | 사용 안 함 |
| I | 부스컷 등록 목록 | 이미지 파일은 나중에 따로 제공 예정 |

## 케모켓과 다른 점
- **부스컷**이 있습니다. 부스 정보에 부스컷 이미지를 보여줘야 합니다.
- **부스원이 여러 명**입니다(리더 + 부스원). 기존엔 대표자 1명만 표시했으므로,
  부스 정보 탭에서 여러 명의 프로필과 X 바로가기를 보여주도록 바꿔야 합니다.
- 리더·부스원 표기가 `닉네임 / X 아이디` 형태인 경우와 X 아이디가 아예 없는 경우가 섞여 있어,
  이름과 X 아이디를 나눠 읽고 X 아이디가 없으면 링크 없이 이름만 보여주는 처리가 필요합니다.
- 일반/성인 부스 구분이 새로 생깁니다.
- 행사 정보(날짜, 장소, 교통편, 날씨 좌표)를 한국 행사장 기준으로 바꿔야 합니다
  ([배치도와 행사 안내](기능-배치도와-행사-안내.md)의 상수들).

## 지켜야 할 것
기존 기능이 깨지지 않아야 합니다: 우선순위 정렬, Google 로그인 동기화, 메모·방문 상태·예산.
localStorage 키와 Firestore 데이터는 부스 ID 기준이므로, 부스 ID 체계가 바뀌면
케모켓 때 저장한 데이터가 새 부스와 섞이지 않도록 따로 고려해야 합니다.
