# Furst Class 개편

> 상태: **1차 완료** (2026-10-02, [PR #3](https://github.com/mononono97/kemoket_list/pull/3)~[#7](https://github.com/mononono97/kemoket_list/pull/7) main 반영). 부스컷은 2026-10-03에 반영했고, 실제 배치도를 받으면 이어서 반영합니다.

## 목표
기존 케모켓(2026-09-20, 도쿄) 부스 목록 사이트를 2026년 11월 말 한국에서 열리는
퍼리 행사 **Furst Class**(https://furst-class.com/)용으로 개편합니다.

## 받은 자료 (2026-10-02)
부스 목록 Google 스프레드시트. 열 구성은 다음과 같습니다.

| 열 | 내용 | 사용 |
|---|---|---|
| A | 부스 번호 | 사용 |
| B | 일반/성인 부스 구분 | 사용 |
| C | 부스 이름 | 사용 |
| D | 부스 리더 | 사용 |
| E, F | 부스원 | 사용 |
| G, H | (제외) | 사용 안 함 |
| I | 부스컷 등록 목록 | 이미지 파일은 나중에 따로 제공 예정 |

## 케모켓과 다른 점
- **부스컷**이 있습니다. 부스 정보에 부스컷 이미지를 보여줘야 합니다.
- **부스원이 여러 명**입니다(리더 + 부스원). 기존엔 대표자 1명만 표시했으므로,
  부스 정보 탭에서 여러 명의 프로필과 X 바로가기를 보여주도록 바꿔야 합니다.
- 리더·부스원 표기가 `닉네임 / X 아이디` 형태인 경우와 X 아이디가 아예 없는 경우가 섞여 있어,
  이름과 X 아이디를 나눠 읽고 X 아이디가 없으면 링크 없이 이름만 보여주는 처리가 필요합니다.
- 일반/성인 부스 구분이 새로 생깁니다.
- 행사 정보(날짜, 장소, 교통편, 날씨 좌표)를 한국 행사장 기준으로 바꿔야 합니다
  ([배치도와 행사 안내](기능-배치도와-행사-안내.md)의 상수들).

## 지켜야 할 것
기존 기능이 깨지지 않아야 합니다: 우선순위 정렬, Google 로그인 동기화, 메모·방문 상태·예산.
저장 데이터는 부스 ID 기준이라, 케모켓 때 저장한 데이터가 새 부스와 섞이지 않도록 아래처럼 정리했습니다.

## 결정 사항
구현은 [PR #3](https://github.com/mononono97/kemoket_list/pull/3)에서 진행 중이며, 화면 쪽 자세한 내용은
[부스원과 부스컷](기능-부스원과-부스컷.md) 문서에 있습니다.

| 항목 | 결정 |
|---|---|
| 부스 데이터 | 스프레드시트를 `data/furstclass_booths.csv`로 저장하고, `tools/build_booths.py`가 이를 읽어 `index.html`의 부스 데이터를 생성 |
| 브랜치 | Furst Class 작업은 `furstclass` 브랜치에서 진행. 케모켓 사이트 마지막 상태(main `137e0ae`)는 `kemoket` 브랜치에 보관 |
| 브라우저 저장 키 | 메모·방문 상태·예산·우선순위·마지막 탭·정렬·언어 키를 `furstclass-*`로 변경. 접속 시 남아 있는 `kemoket-*` 키는 삭제(언어도 초기화되어 처음엔 브라우저 언어를 따름) |
| Firestore | `users/{uid}` 문서의 `furstclass` 필드에 저장. 동기화 때 문서 전체를 덮어쓰므로 케모켓 때의 최상위 필드는 첫 동기화에서 삭제됨 |
| 프로필 사진 | `avatars/`에서 케모켓 작가 사진 629개 삭제, Furst Class 부스원과 겹치는 9개만 유지. 사진이 없는 X 아이디는 이름 첫 글자로 표시 |
| 예산 단위 | 엔 → 원 |
| 부스컷 | `booth-cuts/<부스 번호>.jpg`. 이미지는 사용자가 나중에 제공 |
| 배치도 | 실제 배치도를 받기 전까지 A·B·C 열을 그린 임시 배치도 1장 사용 |
| 두 칸 부스 | 이름이 같고 번호가 이어지는 두 칸은 `A37-38`처럼 한 부스로 합침(4개). 예전 칸 번호로 저장된 값은 자동으로 옮김 |
| 시트에 없는 X 아이디 | 사용자가 알려준 22명의 아이디를 `tools/build_booths.py`의 `HANDLE_FILL`에 적어 채움 |
| 테마 | Furst Class 로고(크림슨·블랙·화이트) 기반 파스텔 톤 → 2026-10-03부터 라이트(모던 미니멀)·다크(카지노 나이트) 두 가지 ([문서](기능-라이트-다크-모드.md)) |
| 기본 언어 | 처음 방문하면 브라우저 언어를 따름(한국어/일본어, 그 외 영어) |
| 행사 정보 | 2026-11-28~29, 엔포드 호텔 청주 |
