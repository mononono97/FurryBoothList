# 선입금

## 무엇을 하나
- 부스 상세 창의 **🟡 방문 예정 · 🟢 방문 완료** 옆에 **💳 선입금** 버튼이 생겼습니다.
  선입금을 받는 부스에서 이 버튼을 켜 두면 됩니다. 방문 상태와는 따로 켜고 끕니다.
- 상단 탭에 **💳 선입금** 탭이 생겼습니다(메모 탭 오른쪽). 선입금을 켠 부스만 보이고,
  탭 이름 옆 숫자가 선입금 부스 수입니다.
  - 제목 옆에 "선입금 부스 n개 · 수령 완료 m개 · 합계 ₩금액"이 표시됩니다.
  - 카드 아래에 "✅ 수령 완료" 또는 "⏳ 수령 전"과 적어 둔 금액이 보입니다.
  - 검색과 우선순위순 정렬은 다른 탭처럼 그대로 됩니다.
- 선입금 탭에서 부스를 누르면 **선입금 창**이 열립니다. 부스 이름, 상품 정보(또는 부스컷),
  부스원 목록은 일반 상세 창과 같고, 그 아래에 다음이 있습니다.
  - **📦 수령 완료로 표시 / ✅ 선입금 수령 완료** 버튼(누를 때마다 바뀜)
  - 선입금 날짜(달력), 선입금 플랫폼, 선입금 금액(원), 선입금 입금자명
  - 적는 즉시 저장되어 따로 저장 버튼이 없습니다.
- 정보를 적어 둔 부스에서 💳 선입금 버튼을 끄면, 적어 둔 정보가 같이 지워진다는 확인창이 먼저 뜹니다
  (기본 포커스는 취소). 아무것도 적지 않았으면 바로 꺼집니다.
- Google 로그인 동기화와 "데이터 초기화"에도 포함됩니다.

## 왜 이렇게 했나
- 2026-10-05 사용자 요청: 선입금을 진행하는 부스가 있어, 방문 예정/완료 옆에 선입금 버튼을 두고
  선입금 부스만 모아 보는 탭과 수령 여부·날짜·플랫폼·금액·입금자명을 적는 창을 원함.
- 선입금 창에는 방문 상태·우선순위·예산·메모·X 타임라인을 넣지 않았습니다. 선입금 탭에서는
  선입금 정보만 보는 것이 목적이라 요청대로 부스 정보·부스원 아래에 선입금 칸만 둡니다.
  방문 상태 등은 다른 탭에서 부스를 열면 그대로 바꿀 수 있습니다.
- 선입금 정보는 메모·방문 상태·예산과 같은 방식(브라우저 저장 + 로그인 시 수동 동기화)으로 저장합니다.
- 선입금 금액은 예산과 따로 셉니다. 예산은 "쓸 계획", 선입금은 "이미 낸 돈"이라 섞지 않았습니다.
- 끌 때 확인창을 두는 이유: 버튼 한 번 잘못 눌러 입금자명·금액 같은 기록이 사라지지 않게 하기 위해서입니다.

## 어떻게 구현했나 (`index.html`)
- localStorage 키 `furstclass-preorder`:
  `{ "A01": { received: true, date: "2026-11-01", platform: "위치폼", amount: 35000, payer: "홍길동" } }`.
  부스가 이 객체에 있으면 선입금이 켜진 것입니다. 빈 칸은 저장하지 않습니다.
- 함수: `loadPreorders()`, `savePreorders()`, `getPreorder()`, `setPreorderOn()`, `setPreorderField()`,
  `preorderHasDetails()`, `getPreorderTotal()`. 글자 칸은 최대 `MAX_PREORDER_TEXT`(100)자.
- 탭: `renderNav()`의 💳 버튼 → `goToRow("PREORDER")`, `VALID_ROWS`에 `PREORDER` 추가.
  `renderGrid()`의 `isPreorderView`가 목록·제목·카드의 `.preorder-line`을 그립니다.
- 창: 일반 상세 창과 공통인 윗부분을 `openBoothModalShell()`로 떼어 냈고,
  `openBoothModal()`(일반)과 `openPreorderModal()`(선입금)이 같이 씁니다. 창을 띄우는 부분은 `showBoothModal()`.
  선입금 탭 카드를 누르면 `openPreorderModal()`, 다른 탭과 배치도에서는 지금처럼 `openBoothModal()`.
- 동기화: `pushToCloud()`가 `preorders`도 올리고, `pullAndMergeFromCloud()`가 부스 단위로 합칩니다
  (같은 부스는 이 기기 값 우선, 다른 데이터와 같은 규칙). 두 칸 부스 번호 이전(`migrateAllMergedBoothIds()`)과
  `resetAllData()`에도 포함.
- 색: 일반 창의 💳 버튼 켜짐은 청록(`#2f8f8a`), 카드의 "수령 완료" 글자는 테마 토큰 `--preorder-done`.

## 확인 방법
1. PC 브라우저로 사이트를 열고 아무 부스나 누름 → 방문 예정·방문 완료 오른쪽에 "💳 선입금" 버튼이 있는지
2. 💳 선입금을 누르면 버튼이 청록색이 되고 상단 탭이 "💳 선입금(1)"로 바뀌는지
3. 💳 선입금 탭 → 그 부스만 보이고 카드에 "⏳ 수령 전"이 있는지
4. 카드를 누름 → 부스 정보·부스원 아래에 수령 완료 버튼과 날짜·플랫폼·금액·입금자명 칸이 있는지
5. 칸을 채우고 수령 완료를 누른 뒤 창을 닫음 → 카드가 "✅ 수령 완료 · ₩금액", 제목 줄 합계가 맞는지
6. 새로고침해도 그대로인지, 다른 탭에서 그 부스를 열어 💳 선입금을 끄려 하면 확인창이 뜨는지(취소하면 유지)
7. 로그인 상태라면 "지금 동기화" 후 다른 기기에서도 동기화해서 선입금 정보가 보이는지
