# 라이트·다크 모드

## 무엇을 하나
- 사이트가 두 가지 화면(테마)으로 보입니다.
  - **라이트(모던 미니멀)**: 밝은 오프화이트 배경, 흰색 반투명 상단바, 그림자가 있는 둥근 흰 카드. 크림슨은 강조에만 씁니다.
  - **다크(카지노 나이트)**: 검정 배경, 골드 선과 크림슨 강조, 세리프 글꼴 제목. 행사 컨셉("갬블링 캣")에 맞춘 어두운 고급 톤입니다.
- 설정 메뉴(톱니바퀴)의 **☀️ 라이트 / 🌙 다크** 버튼으로 고를 수 있고, 고른 값은 이 브라우저에 저장됩니다.
- 한 번도 고르지 않았다면 브라우저(기기)의 다크 모드 설정을 따릅니다. 기기 설정이 라이트거나 알 수 없으면 라이트입니다. 고르지 않은 상태에서는 기기 설정을 바꾸면 사이트도 바로 따라 바뀝니다.
- PC(화면 폭 701px 이상)에서는 스크롤해도 상단바가 위에 붙어 있습니다. 모바일에서는 화면을 많이 가려서 붙지 않습니다.
- 팝오버·모달·설정 메뉴는 두 테마 모두 어두운 패널입니다(다크에서는 골드 테두리).
- 행사 안내의 공식 X 소식도 테마에 맞춰 밝게/어둡게 불러옵니다.

## 왜 이렇게 했나
- 2026-10-03 디자인 개선 제안에서 시안 A(카지노 나이트)·B(모던 미니멀)·C(트럼프 카드)를 비교했고, 사용자가 A와 B를 둘 다 쓰기로 결정했습니다. 기본은 라이트, 브라우저가 다크 모드면 다크.
- 라이트는 부스컷 수십 장이 한 화면에 있어도 정돈돼 보이고 행사장(밝은 실내, 휴대폰)에서 읽기 편합니다. 다크는 행사 분위기를 살리고 어두운 곳에서 눈이 덜 부십니다.
- 웹폰트(Google Fonts)는 쓰지 않았습니다. 사이트의 보안 정책(CSP)이 외부 글꼴을 막고 있고, 오프라인에서도 같은 모양으로 보이게 하려고 시스템 글꼴만 씁니다. 다크의 제목 글꼴은 Georgia 계열 세리프입니다.
- 열 제목 옆 장식 점은 메모·배치도·행사 안내 탭에서 이모지 옆에 붙어 어색해서 뺐습니다.

## 어떻게 구현했나
- 색과 모양은 모두 `<style>` 맨 위 CSS 변수로 정합니다. `:root`가 라이트 값, `:root[data-theme="dark"]`가 다크 값입니다.
  - 페이지: `--paper`(배경), `--page-glow`(다크 상단 은은한 빛), `--ink`, `--text-2`, `--muted`, `--line`, `--card-bg`, `--hover-tint`, `--display-font`
  - 상단바: `--header-bg`, `--header-fg`, `--header-sub`, `--header-border`, `--chip-*`(열·탭 버튼), `--search-*`
  - 부스 카드: `--card-border`, `--card-border-hover`, `--card-radius`, `--card-shadow`, `--card-shadow-hover`, `--id-color`, `--id-bg`, `--big-letter`, `--heading-rule`, `--note-bg`, `--planned-bg`, `--visited-bg`, `--pill-active-*`
  - 패널(팝오버·모달·설정 메뉴): `--panel`, `--panel-2`, `--panel-border`, `--on-panel`(패널 위 글자), `--moss-light`(패널 위 보조 글자)
- 예전에는 `--paper`가 배경색이면서 어두운 패널 위 글자색으로도 쓰였는데, 다크에서는 배경이 어두워지므로 패널 글자색을 `--on-panel`로 분리했습니다.
- `<head>`의 작은 스크립트가 화면을 그리기 전에 `<html data-theme>`을 정합니다(다크 사용자에게 밝은 화면이 잠깐 번쩍이지 않게).
- 설정 메뉴: `#themeSwitch` 버튼, `currentTheme()`, `applyTheme()`, `updateThemeSwitch()`. 번역 키 `themeLight`, `themeDark`.
- 저장: localStorage `furstclass-theme`(`light`/`dark`). 직접 고른 경우에만 저장하고, 데이터 초기화와 Google 동기화 대상이 아닙니다(언어 설정과 같음).
- 기기 설정 변경 감지: `matchMedia("(prefers-color-scheme: dark)")`의 `change` 이벤트. 저장된 값이 없을 때만 따라갑니다.
- 공식 X 소식: `createTweet(..., { theme: currentTheme() })`. 행사 안내를 보는 중에 테마를 바꾸면 `renderGrid()`로 다시 그립니다.

## 확인 방법
1. 기기(OS)나 브라우저를 라이트 모드로 두고 사이트를 열면 라이트, 다크 모드로 두면 다크로 열리는지 확인
2. 설정 메뉴에서 ☀️ 라이트 / 🌙 다크를 눌러 바뀌는지, 새로고침해도 고른 값이 유지되는지 확인
3. 다른 값을 고른 뒤 기기 설정을 바꿔도 사이트는 고른 값 그대로인지 확인
4. 두 테마에서 부스 목록, 팝오버, 메모 탭(방문 필터·총 예산), 배치도, 행사 안내, 도움말, 초기화 확인창이 잘 읽히는지 확인
5. 메모·방문 예정/완료·우선순위 표시 색이 두 테마 모두에서 구분되는지 확인
6. PC에서 스크롤하면 상단바가 위에 붙어 있고, 휴대폰에서는 함께 올라가는지 확인
7. 언어를 바꿔도 테마 버튼 이름이 해당 언어로 바뀌는지 확인
