# 부스 목록과 부스 상세 창

## 무엇을 하나
- 상단에 부스 열 탭(Furst Class: A·B·C, 케모켓 때는 A~S)과 "전체" 탭이 있고, 탭을 누르면 해당 열의 부스 카드가 나옵니다.
- 검색창으로 서클명·대표자명을 찾을 수 있습니다.
- **PC(화면 폭 641px 이상에서 마우스로 클릭)**: 부스 카드를 누르면 새 창 대신 **누른 카드가 있는 줄 바로 아래에 상세가 펼쳐집니다**(2026-10-05~).
  - 왼쪽 칸: 맨 위에 "[A15] PPP2"처럼 부스 번호와 이름을 큰 글씨로, 그 아래 상품 정보(또는 부스컷)
  - 오른쪽 칸: 맨 위에 부스원 목록을 가로 한 줄로(많으면 다음 줄로 넘어감, 최대 6명인 부스도 두 줄), 그 아래 🟡 방문 예정 · 🟢 방문 완료 · 💳 선입금, 1~3순위, 예산, 메모
  - 선입금 탭에서는 오른쪽 칸이 선입금 정보(수령 완료·날짜·플랫폼·금액·입금자명·선입금 메모)로 바뀝니다.
  - 위쪽 작은 화살표가 누른 카드를 가리키고, 펼친 카드는 살짝 떠 있는 모양으로 표시됩니다.
  - 같은 카드를 다시 누르거나 오른쪽 위 ✕, Esc 키로 닫힙니다. 다른 카드를 누르면 그 카드 줄 아래로 옮겨 펼쳐집니다(한 번에 하나).
  - 창 폭이 760px 이하로 좁으면 두 칸을 위아래로 쌓습니다. 상세가 화면 아래로 잘리면 누른 카드 이름이 보이는 만큼만 남기고 자동으로 스크롤합니다.
- **모바일(화면 폭 640px 이하이거나 손가락·펜으로 누른 경우)**: 지금처럼 화면을 거의 채우는 큰 창(모달, 최대 폭 720px)으로 열립니다. 부스컷은 화면 높이 62%까지. 창 맨 위 제목은 PC처럼 "[A03] GYM LIGER" 형태로 20px 크게 보입니다(배치도 창도 같음). ✕ 버튼이나 창 바깥을 누르면 닫힙니다.
- **배치도 탭**에서 부스를 누르면 PC에서도 화면 가운데 창(모달, 폭 560px, 부스컷은 화면 높이 55%까지)이 뜹니다. 배치도에는 카드 줄이 없어서입니다. ✕·창 바깥·Esc로 닫힙니다.
- 2026-10-03 이전에는 PC에서 카드 위에 말풍선(팝오버)으로 열렸습니다(아래 변경 기록 참고).
- 프로필 사진을 클릭하면 대표자의 X 프로필로 바로 이동합니다(모든 탭 공통).
- 새로고침해도 마지막으로 보던 탭이 유지됩니다.

## 왜 이렇게 했나
- 처음엔 마우스 호버로 팝오버(말풍선)를 열었지만 모바일에서 쓸 수 없어 클릭 방식으로 바꿨습니다.
- 말풍선은 카드 위아래 남는 공간만큼만 커질 수 있어서, 모바일이나 화면 중간 카드에서는 창이 작게 보였습니다. 폭을 넓히거나(#23) 스크롤에 맞춰 높이를 다시 맞추는 방법도 시도했지만, 사용자 요청(2026-10-03)으로 PC·모바일 모두 화면 가운데 모달로 통일하고 말풍선 코드는 지웠습니다.
- 모바일 판정은 화면 폭과 실제 누른 입력 종류(손가락·펜)로 합니다. 처음(#23)에는 `(hover:none) and (pointer:coarse)` 미디어쿼리를 썼는데 갤럭시 폴드 펼친 화면에서 큰 창이 안 뜬다는 제보가 있었습니다(S펜 지원 기기는 hover가 PC처럼 잡히는 경우가 있음).
- 모달 안에서 스크롤해도 ✕ 버튼은 위쪽에 고정되고, 모달이 열린 동안 뒤 페이지는 스크롤되지 않습니다.
- 상단바 고정(sticky)은 화면을 너무 많이 차지해 해제했습니다(이후 #22에서 PC만 다시 고정).
- PC 펼침 상세(2026-10-05 사용자 요청): PC에서는 창이 뜨면 뒤의 카드 목록이 가려져, 목록을 보면서 바로 옆 부스를 이어서 확인하기 불편했습니다. 사용자가 보내 준 그림처럼 카드 줄 사이에 왼쪽 부스 정보·부스원, 오른쪽 방문 상태·메모로 펼치게 했습니다. 모바일은 화면이 좁아 두 칸이 들어가지 않으므로 기존 큰 창을 그대로 씁니다.
- 같은 날 후속 요청으로, 부스 이름·번호를 크게 보여 알아보기 쉽게 하고 부스원은 오른쪽 위에 가로로 늘어놓아 왼쪽 부스컷 아래 빈 공간을 줄였습니다.
- 펼침 상세의 칸 내용은 모달과 같은 함수로 만들어서, 버튼·저장 동작이 모달과 똑같습니다(한쪽만 고치다 어긋나는 일이 없게).

## 어떻게 구현했나
- 렌더링: `renderNav()`, `renderGrid()`, 탭 이동 `goToRow()` (`CURRENT_ROW_KEY`에 저장)
- 부스 상세 모달: `openBoothModal(boothId)`, `closeModal()`. 모바일 카드 클릭과 배치도 클릭이 씁니다. 열 때마다 내용을 새로 만들어서, 저장하지 않은 메모 초안은 닫으면 사라집니다.
- 상세 내용 함수(모달·펼침 상세 공통): `fillBoothInfo(container, booth, { withHead, withMembers })`(이름·상품 정보/부스컷·부스원. 모달은 `withHead:false`, 펼침 상세는 둘 다 `false`로 부르고, 둘 다 큰 제목 `buildBoothTitle()`(`.booth-title`, 모달 20px·펼침 상세 26px)을 따로 달고 `buildMemberList()`를 오른쪽 칸 맨 앞에 붙임. 가로 배치는 `.booth-inline .member-list`의 `flex-wrap`), `fillBoothActions()`(방문 상태·선입금·우선순위·예산·메모), `fillPreorderActions()`(선입금 정보). 모달은 한 칸에 차례로 붙이고, 펼침 상세는 왼쪽 `.booth-inline-info`·오른쪽 `.booth-inline-actions`에 나눠 붙입니다.
- PC 펼침 상세: `openInlineDetail(boothId, kind)`(`kind`는 `"booth"`/`"preorder"`, 같은 부스를 다시 누르면 닫힘), `closeInlineDetail()`, `placeInlineDetail()`. 상세(`.booth-inline`, `grid-column:1 / -1`)를 누른 카드와 `offsetTop`이 같은 마지막 카드 바로 뒤에 끼워 넣습니다. `renderGrid()` 끝과 창 크기 변경(`resize`) 때 다시 불러 위치를 맞추므로, 메모 저장·정렬·선입금 수정으로 목록을 다시 그려도 펼친 상세가 유지됩니다(목록에서 부스가 빠지면 닫힘). 배치도·행사 안내 탭으로 가면 닫힙니다. 스크롤은 `scrollInlineDetailIntoView()`. 펼친 카드에는 `.detail-open` 클래스.
- Esc: 큰 이미지·모달·확인창이 떠 있으면 그것만 닫고, 아무것도 없을 때 펼침 상세를 닫습니다.
- 큰 창 판정: `useBoothModal()`. 마지막 `pointerdown`의 `pointerType`이 `touch`/`pen`이거나 화면 폭이 640px 이하면 참. 참이면 모달에 `booth-modal-full`, 배경에 `booth-full` 클래스가 붙습니다. PC용 크기는 `.modal.booth-modal`.
- 모달이 열려 있으면 `<html>`에 `modal-open` 클래스가 붙어 뒤 페이지 스크롤을 막습니다. `overflow:hidden`은 `<html>`에만 겁니다. `<body>`에도 걸면 body가 스크롤 기준이 되어 PC 상단바의 고정(sticky)이 풀리고, 스크롤해 둔 상태에서 창을 열면 상단바가 화면 위로 사라집니다.
- 프로필 사진 경로: `localAvatarUrl()`

## 확인 방법
1. 탭 A, 전체를 차례로 눌러 카드가 바뀌는지 확인
2. PC에서 첫 줄 카드를 눌러 그 줄 바로 아래에 상세가 펼쳐지는지(왼쪽 부스컷·부스원, 오른쪽 방문 상태·우선순위·예산·메모), 화살표가 누른 카드를 가리키는지 확인
3. 같은 카드를 다시 누르기, ✕ 버튼, Esc 키로 각각 닫히는지, 다른 줄 카드를 누르면 그 줄 아래로 옮겨지는지 확인
4. 펼친 상세에서 방문 상태·우선순위·예산·메모를 바꾸면 위 카드 표시(색·테두리)가 바로 바뀌는지, 닫았다 다시 열면 값이 남아 있는지 확인. "우선순위순 정렬"을 눌러도 상세가 그 부스 아래에 그대로 있는지 확인
5. 선입금 탭에서 카드를 눌러 오른쪽에 선입금 정보 칸이 펼쳐지는지, 수령 완료를 눌러도 상세가 닫히지 않는지 확인
6. 배치도 탭에서 부스를 누르면 화면 가운데 창이 뜨고, ✕·창 바깥·Esc로 닫히는지 확인
7. 브라우저 창 폭을 줄였다 늘려도 상세가 누른 카드 줄 아래에 맞춰지는지 확인
8. 휴대폰(또는 개발자 도구 모바일 화면)에서 카드를 눌러 지금처럼 화면을 거의 채우는 큰 창이 뜨는지 확인
9. 프로필 사진을 눌러 X 프로필이 새 탭에서 열리는지 확인
10. 새로고침 후 같은 탭이 유지되는지 확인
