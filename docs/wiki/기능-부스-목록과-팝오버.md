# 부스 목록과 팝오버

## 무엇을 하나
- 상단에 부스 열 탭(Furst Class: A·B·C, 케모켓 때는 A~S)과 "전체" 탭이 있고, 탭을 누르면 해당 열의 부스 카드가 나옵니다.
- 검색창으로 서클명·대표자명을 찾을 수 있습니다.
- 부스 카드를 클릭(탭)하면 팝오버가 열려 대표자 X 타임라인, 메모, 방문 상태 등을 보여줍니다.
- 프로필 사진을 클릭하면 대표자의 X 프로필로 바로 이동합니다(모든 탭 공통).
- 새로고침해도 마지막으로 보던 탭이 유지됩니다.

## 왜 이렇게 했나
- 처음엔 마우스 호버로 팝오버를 열었지만 모바일에서 쓸 수 없어 클릭 방식으로 바꿨습니다.
- 팝오버가 여러 개 열리면 화면이 복잡해져 새 팝오버를 열면 기존 것은 닫습니다.
- 팝오버가 화면 가장자리를 벗어나지 않도록 위치를 보정하고, 위쪽 공간이 없으면 카드 아래로 뒤집습니다.
- 카드가 스크롤로 화면 밖으로 나가면 팝오버를 자동으로 닫되, 작성 중인 메모는 임시로 유지합니다.
- 상단바 고정(sticky)은 화면을 너무 많이 차지해 해제했습니다.

## 어떻게 구현했나
- 렌더링: `renderNav()`, `renderGrid()`, 탭 이동 `goToRow()` (`CURRENT_ROW_KEY`에 저장)
- 팝오버: `makePopover()`, `positionPopover()`, `closeAllPopovers()`
- 모달(큰 화면용 부스 상세): `openBoothModal()`, `closeModal()`
- X 위젯: `ensureTwitterWidgets()`, `loadTimelineInto()`
- 프로필 사진 경로: `localAvatarUrl()`

## 확인 방법
1. 탭 A, 전체를 차례로 눌러 카드가 바뀌는지 확인
2. 카드를 눌러 팝오버가 열리고, 다른 카드를 누르면 이전 팝오버가 닫히는지 확인
3. 화면 맨 왼쪽/오른쪽 카드에서 팝오버가 잘리지 않는지 확인
4. 프로필 사진을 눌러 X 프로필이 새 탭에서 열리는지 확인
5. 새로고침 후 같은 탭이 유지되는지 확인
