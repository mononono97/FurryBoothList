# 부스 목록과 팝오버

## 무엇을 하나
- 상단에 부스 열 탭(Furst Class: A·B·C, 케모켓 때는 A~S)과 "전체" 탭이 있고, 탭을 누르면 해당 열의 부스 카드가 나옵니다.
- 검색창으로 서클명·대표자명을 찾을 수 있습니다.
- 부스 카드를 클릭(탭)하면 팝오버가 열려 대표자 X 타임라인, 메모, 방문 상태 등을 보여줍니다.
- 모바일(화면 폭 640px 이하이거나, 손가락·펜으로 카드를 누른 경우)에서는 팝오버 대신 화면을 거의 채우는 모달(최대 폭 720px)로 열립니다. 부스컷은 화면 높이의 62%까지 커져 스크롤 없이 통째로 보입니다. 오른쪽 위 ✕ 버튼이나 창 바깥 여백을 터치하면 닫힙니다.
- 프로필 사진을 클릭하면 대표자의 X 프로필로 바로 이동합니다(모든 탭 공통).
- 새로고침해도 마지막으로 보던 탭이 유지됩니다.

## 왜 이렇게 했나
- 처음엔 마우스 호버로 팝오버를 열었지만 모바일에서 쓸 수 없어 클릭 방식으로 바꿨습니다.
- 팝오버가 여러 개 열리면 화면이 복잡해져 새 팝오버를 열면 기존 것은 닫습니다.
- 팝오버가 화면 가장자리를 벗어나지 않도록 위치를 보정하고, 위쪽 공간이 없으면 카드 아래로 뒤집습니다.
- 카드가 스크롤로 화면 밖으로 나가면 팝오버를 자동으로 닫되, 작성 중인 메모는 임시로 유지합니다.
- 상단바 고정(sticky)은 화면을 너무 많이 차지해 해제했습니다.
- PC 팝오버와 배치도 부스 상세 모달은 좁아 보인다는 요청으로 폭을 420px로 넓혔습니다(기존 팝오버 300px, 모달 340px). 화면이 좁으면 화면 폭에 맞춰 줄어듭니다.
- 모바일에서는 팝오버 폭이 250px밖에 안 되어 부스컷·메모 등이 너무 작게 보였습니다. 그래서 모바일만 배치도에서 쓰던 부스 상세 모달을 크게 띄우도록 바꿨고, PC는 기존 팝오버 그대로입니다. 모달 안에서 스크롤해도 ✕ 버튼은 위쪽에 고정되고, 모달이 열린 동안 뒤 페이지는 스크롤되지 않습니다.

## 어떻게 구현했나
- 렌더링: `renderNav()`, `renderGrid()`, 탭 이동 `goToRow()` (`CURRENT_ROW_KEY`에 저장)
- 팝오버: `makePopover()`, `positionPopover()`, `closeAllPopovers()`
- 모달(부스 상세, 배치도·모바일 부스 카드 공용): `openBoothModal()`, `closeModal()`
- 모바일 판정: `useBoothModal(e)`. 클릭한 입력이 손가락·펜(`pointerType`이 `touch`/`pen`)이거나 화면 폭이 640px 이하면 참. 참이면 모달에 `booth-modal-full`, 배경에 `booth-full` 클래스가 붙어 큰 창 스타일이 적용됩니다.
- 처음(#23)에는 `(hover:none) and (pointer:coarse)` 미디어쿼리로 터치 기기를 골랐는데, 갤럭시 폴드 펼친 화면에서 큰 창이 안 뜬다는 제보가 있어 실제 누른 입력 종류로 판단하도록 바꿨습니다(S펜 지원 기기는 hover가 PC처럼 잡히는 경우가 있음).
- 모달이 열려 있으면 `<html>`에 `modal-open` 클래스가 붙어 뒤 페이지 스크롤을 막습니다.
- X 위젯: `ensureTwitterWidgets()`, `loadTimelineInto()`
- 프로필 사진 경로: `localAvatarUrl()`

## 확인 방법
1. 탭 A, 전체를 차례로 눌러 카드가 바뀌는지 확인
2. 카드를 눌러 팝오버가 열리고, 다른 카드를 누르면 이전 팝오버가 닫히는지 확인
3. 화면 맨 왼쪽/오른쪽 카드에서 팝오버가 잘리지 않는지 확인
4. 프로필 사진을 눌러 X 프로필이 새 탭에서 열리는지 확인
5. 새로고침 후 같은 탭이 유지되는지 확인
6. 휴대폰(또는 PC 브라우저 개발자 도구의 모바일 화면)에서 카드를 눌러 큰 모달이 뜨는지, ✕ 버튼과 창 밖 터치로 닫히는지, 모달 안에서 방문 상태·우선순위·예산·메모가 저장되고 카드에 반영되는지 확인
7. PC 화면에서는 여전히 말풍선 팝오버로 열리는지 확인
