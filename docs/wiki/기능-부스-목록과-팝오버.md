# 부스 목록과 부스 상세 창

## 무엇을 하나
- 상단에 부스 열 탭(Furst Class: A·B·C, 케모켓 때는 A~S)과 "전체" 탭이 있고, 탭을 누르면 해당 열의 부스 카드가 나옵니다.
- 검색창으로 서클명·대표자명을 찾을 수 있습니다.
- 부스 카드를 클릭(탭)하면 **화면 가운데에 부스 상세 창(모달)** 이 열려 부스컷, 부스원, 대표자 X 글, 방문 상태, 우선순위, 예산, 메모를 보여줍니다. 오른쪽 위 ✕ 버튼이나 창 바깥을 누르면 닫히고, PC에서는 Esc 키로도 닫힙니다. 배치도에서 부스를 눌러도 같은 창이 뜹니다.
  - PC(마우스로 클릭): 폭 560px, 높이는 내용만큼(최대 화면 높이 90%). 부스컷은 화면 높이 55%까지.
  - 모바일(화면 폭 640px 이하이거나 손가락·펜으로 누른 경우): 화면을 거의 채우는 큰 창(최대 폭 720px). 부스컷은 화면 높이 62%까지.
- 2026-10-03 이전에는 PC에서 카드 위에 말풍선(팝오버)으로 열렸습니다(아래 변경 기록 참고).
- 프로필 사진을 클릭하면 대표자의 X 프로필로 바로 이동합니다(모든 탭 공통).
- 새로고침해도 마지막으로 보던 탭이 유지됩니다.

## 왜 이렇게 했나
- 처음엔 마우스 호버로 팝오버(말풍선)를 열었지만 모바일에서 쓸 수 없어 클릭 방식으로 바꿨습니다.
- 말풍선은 카드 위아래 남는 공간만큼만 커질 수 있어서, 모바일이나 화면 중간 카드에서는 창이 작게 보였습니다. 폭을 넓히거나(#23) 스크롤에 맞춰 높이를 다시 맞추는 방법도 시도했지만, 사용자 요청(2026-10-03)으로 PC·모바일 모두 화면 가운데 모달로 통일하고 말풍선 코드는 지웠습니다.
- 모바일 판정은 화면 폭과 실제 누른 입력 종류(손가락·펜)로 합니다. 처음(#23)에는 `(hover:none) and (pointer:coarse)` 미디어쿼리를 썼는데 갤럭시 폴드 펼친 화면에서 큰 창이 안 뜬다는 제보가 있었습니다(S펜 지원 기기는 hover가 PC처럼 잡히는 경우가 있음).
- 모달 안에서 스크롤해도 ✕ 버튼은 위쪽에 고정되고, 모달이 열린 동안 뒤 페이지는 스크롤되지 않습니다.
- 상단바 고정(sticky)은 화면을 너무 많이 차지해 해제했습니다(이후 #22에서 PC만 다시 고정).

## 어떻게 구현했나
- 렌더링: `renderNav()`, `renderGrid()`, 탭 이동 `goToRow()` (`CURRENT_ROW_KEY`에 저장)
- 부스 상세 모달: `openBoothModal(boothId)`, `closeModal()`. 카드 클릭과 배치도 클릭이 같은 함수를 씁니다. 열 때마다 내용을 새로 만들어서, 저장하지 않은 메모 초안은 닫으면 사라집니다.
- 큰 창 판정: `useBoothModal()`. 마지막 `pointerdown`의 `pointerType`이 `touch`/`pen`이거나 화면 폭이 640px 이하면 참. 참이면 모달에 `booth-modal-full`, 배경에 `booth-full` 클래스가 붙습니다. PC용 크기는 `.modal.booth-modal`.
- 모달이 열려 있으면 `<html>`에 `modal-open` 클래스가 붙어 뒤 페이지 스크롤을 막습니다. `overflow:hidden`은 `<html>`에만 겁니다. `<body>`에도 걸면 body가 스크롤 기준이 되어 PC 상단바의 고정(sticky)이 풀리고, 스크롤해 둔 상태에서 창을 열면 상단바가 화면 위로 사라집니다.
- X 위젯: `ensureTwitterWidgets()`, `loadTimelineInto()`(X 스크립트가 막히면 오류 없이 실패 문구 표시)
- 프로필 사진 경로: `localAvatarUrl()`

## 확인 방법
1. 탭 A, 전체를 차례로 눌러 카드가 바뀌는지 확인
2. PC에서 화면 위·중간·아래 카드를 눌러 모두 화면 가운데에 같은 크기로 열리는지 확인
3. ✕ 버튼, 창 바깥 클릭, Esc 키로 각각 닫히는지 확인
4. 모달에서 방문 상태·우선순위·예산·메모를 바꾸고 닫았을 때 카드 표시(색·테두리)가 바뀌는지, 다시 열면 값이 남아 있는지 확인
5. 휴대폰(또는 개발자 도구 모바일 화면)에서 카드를 눌러 화면을 거의 채우는 큰 창이 뜨는지 확인
6. 프로필 사진을 눌러 X 프로필이 새 탭에서 열리는지 확인
7. 새로고침 후 같은 탭이 유지되는지 확인
