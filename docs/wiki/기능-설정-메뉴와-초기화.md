# 설정 메뉴와 데이터 초기화

## 무엇을 하나
- 헤더의 톱니바퀴 버튼을 누르면 설정 메뉴가 열립니다: 언어(KO/EN/JP), 화면 테마(☀️ 라이트/🌙 다크, [라이트·다크 모드](기능-라이트-다크-모드.md)), 도움말, 지금 동기화, 전체 데이터 초기화.
- 메뉴는 화면 크기와 상관없이 항상 화면 안쪽에 보입니다.
- "전체 데이터 초기화"는 커스텀 확인창을 거칩니다. 기본 포커스가 **취소**에 있고, 배경 클릭이나 Esc로도 취소됩니다.
- Google 로그인 중이면 확인창에 "클라우드에 저장된 데이터(다른 기기 포함)도 모두 삭제된다"는 경고가 나오고, 확인하면 클라우드(Firestore `users/{uid}.furstclass`)도 비웁니다. 클라우드를 지우지 못하면(인터넷 끊김 등) 안내 후 이 기기 데이터도 지우지 않고 멈춥니다.

## 왜 이렇게 했나
- 헤더에 버튼이 늘어나 정리하려고 설정 메뉴로 모았습니다.
- 예전에는 로그인 중이어도 이 기기만 지워서, 다음에 페이지를 열 때 로그인 자동 병합으로 클라우드 값이 다시 돌아왔습니다(2026-10-08 개선점 점검에서 발견, 사용자 요청으로 클라우드도 지우게 함). 클라우드를 먼저 지우고 실패하면 멈추는 것도 같은 이유입니다(기기만 지워지면 다시 되살아남).
- 브라우저 기본 `confirm()`은 기본 포커스가 확인 쪽이라 엔터 한 번에 데이터가 지워질 위험이 있어 커스텀 확인창으로 바꿨습니다.

## 어떻게 구현했나
- 메뉴: `positionSettingsMenu()`(position:fixed + 화면 안으로 클램핑), `closeSettingsMenu()`
- 초기화: `resetAllData()`, `showConfirmDialog()`, `closeConfirmDialog()`. 로그인 중(`firebaseReady && currentUser`)이면 문구 `resetConfirmCloud`, 클라우드 문서를 빈 값으로 `set()`(쓰기 1회), 실패 시 `resetCloudFail`. 기기에 데이터가 없어도 로그인 중이면 클라우드를 지울 수 있게 확인창을 띄움

## 확인 방법
1. 창 크기를 줄여도 설정 메뉴가 화면 밖으로 나가지 않는지 확인
2. 초기화 → 확인창이 뜨면 엔터 → 취소되는지(데이터 유지) 확인
3. Esc, 배경 클릭으로도 취소되는지 확인
4. 로그인한 상태에서 초기화 → 클라우드 경고 문구가 나오는지, 확인 후 새로고침해도 데이터가 돌아오지 않는지, 다른 기기에서 "지금 동기화"를 눌러도 지운 데이터가 없는지 확인(다른 기기에 남아 있던 로컬 값은 그 기기에서 동기화하면 다시 올라감)
