# 사이트 구조

빌드 과정이 없는 정적 사이트입니다. 파일을 그대로 올리면 동작합니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 사이트 전체 (HTML + CSS + JS, 부스 데이터 포함) |
| `sw.js` | 오프라인 열람용 서비스 워커 |
| `avatars/` | 부스 대표자 X 프로필 사진. 파일명은 `<X 핸들>.jpg` |
| `favicon.png` | 파비콘 |
| `.gitignore` | `main.py`(로컬 전용 스크립트) 제외 |

## 부스 데이터
`index.html` 안의 `BOOTHS` 배열에 들어 있습니다.

```js
{ "id": "A-01", "block": "A", "name": "서클명", "rep": "대표자명", "twitter": "x핸들", "tweetUrl": "" }
```
- `block`: 부스 열(A~S). `ALL_ROWS`에 열 목록이 있고, 열마다 탭이 생깁니다.
- `twitter`: X 핸들. 없으면 `null`. 프로필 사진(`avatars/<핸들>.jpg`)과 X 링크에 쓰입니다.
- 핸들의 대소문자는 실제 파일명과 정확히 같아야 합니다. 배포 환경(Cloudflare)은
  대소문자를 구분합니다. ([변경 이력](변경-이력.md) 2026-09-18 참고)

## 저장 방식 (localStorage 키)
| 키 | 내용 |
|---|---|
| `kemoket-notes` | 부스별 메모 `{ "A-01": "..." }` |
| `kemoket-visit-status` | 방문 예정/완료 |
| `kemoket-budget` | 부스별 예산(엔) |
| `kemoket-priority` | 부스별 우선순위 1~3 |
| `kemoket-sort-priority` | 우선순위 정렬 켜짐 여부 |
| `kemoket-current-row` | 마지막으로 보던 탭 |
| `kemoket-lang` | 선택 언어 |

로그인하면 메모·방문 상태·예산·우선순위가 Firestore `users/<uid>` 문서에도 저장됩니다.
자세한 내용은 [Google 로그인과 동기화](기능-Google-로그인-동기화.md).

## 외부 서비스
- Firebase Authentication(Google) + Firestore: 로그인·동기화 (프로젝트 `boothlist-4589c`)
- X 타임라인 위젯: 팝오버에서 대표자 타임라인 표시
- Open-Meteo: 행사 당일 날씨 (API 키 불필요)
- Google Maps 임베드: 약도
- `index.html` 상단의 Content-Security-Policy에 허용 도메인이 정리되어 있으므로,
  새 외부 서비스를 붙일 때는 여기도 함께 고쳐야 합니다.

## 배포
Cloudflare에서 정적 호스팅합니다. main 브랜치에 반영되면 배포됩니다.
