# 첫 방문 안내와 성인 부스 안내

## 무엇을 하나
- **첫 방문 도움말**: 이 브라우저로 사이트를 처음 열면 도움말 창이 자동으로 한 번 열립니다. 사이트 소개와 "📖 사용법 설명서 보기" 버튼을 바로 보여 주기 위해서입니다. 닫은 뒤로는 다시 자동으로 열리지 않고, 설정 메뉴 → 도움말로 언제든 다시 볼 수 있습니다.
- **성인 부스 안내**: 성인 부스(B·C 열, 카드에 `18+` 표시)를 처음 누르면 부스 상세 위에 안내 창이 뜹니다.
  > 🔞 성인 부스 안내
  > 성인 부스는 행사 당일 추가적인 인증이 필요할 수 있으며, 미성년자의 경우 구매가 어려울 수 있습니다.

  "확인"을 눌러 닫으면 그 기기에서는 다시 뜨지 않습니다. 창 밖을 누르거나 Esc로 닫으면 다음에 성인 부스를 열 때 다시 뜹니다. 목록 카드(PC 펼침 상세·모바일 창), 선입금 탭, 배치도 어디서 열어도 똑같이 동작합니다. 영어·일본어 화면에서는 번역된 문구가 나옵니다.

## 왜 이렇게 했나
- 2026-10-06 사용자 요청: 처음 오는 사람에게 도움말로 안내하고, 성인 부스를 처음 누르는 사람에게 당일 인증·미성년자 구매 안내를 한 번 보여 주기.
- **이미 쓰던 사람에게는 도움말을 띄우지 않습니다.** 이 브라우저에 `furstclass-*` 값(보던 탭, 언어, 메모 등)이 하나라도 있으면 첫 방문이 아닌 것으로 봅니다. 그래서 이 기능이 배포돼도 기존 사용자 화면에 도움말이 갑자기 뜨지 않습니다.
- **"다시 안 띄우기"는 기기마다 따로 저장하고 Google 로그인 동기화에는 넣지 않았습니다.** 안내는 개인 데이터가 아니고, 새 기기(예: 행사장에서 쓰는 휴대폰)에서 한 번 더 보는 정도는 문제가 없으며, 동기화 데이터 구조(`users/{uid}.furstclass`)를 건드리지 않아 기존 동기화가 깨질 위험이 없기 때문입니다.
- 성인 부스 안내는 "확인"을 눌렀을 때만 기억합니다. 실수로 창 밖을 눌러 닫은 사람에게는 다시 보여 주는 게 요청 취지("확인 버튼을 눌러 닫으면")에 맞습니다.
- 안내 창은 새로 만들지 않고 초기화 확인에 쓰던 대화상자(`#confirmBackdrop`)를 "확인" 버튼 하나짜리로 재사용했습니다.

## 어떻게 구현했나
- 첫 방문 판단: `isFirstVisit`(다른 값이 저장되기 전, `STORAGE_PREFIX` 정의 바로 아래에서 계산). 첫 방문이면 `furstclass-welcome-seen` 을 남기고, 첫 화면을 그린 뒤 `openHelpModal()` 호출.
- 성인 부스 안내: `maybeShowAdultNotice(booth)` 가 `booth.adult` 이고 `furstclass-adult-notice-seen` 이 없을 때 `showNoticeDialog(t("adultNotice"))` 를 띄움. 호출 위치는 `openInlineDetail()`(PC 펼침 상세)과 `showBoothModal(booth)`(부스 창·선입금 창, 배치도 포함).
- `showNoticeDialog()`: 취소 버튼을 숨기고 확인 버튼에 `.primary`(강조색) 스타일. `showConfirmDialog()` 는 열 때마다 취소 버튼과 `.danger` 스타일을 되돌려 초기화 확인창 모양은 그대로.
- 문구: `adultNotice`, `ok` (KO/EN/JP). 한국어는 "성인 부스는 행사 당일 / 추가적인 인증이 필요할 수 있으며, / 미성년자의 경우 구매가 어려울 수 있습니다." 세 줄로 직접 나누고, 영어·일본어는 창 폭에 맞춰 자연스럽게 줄바꿈되게 둠. 대화상자 글은 한국어일 때만 `word-break:keep-all`(단어 중간에서 안 끊김). 일본어는 띄어쓰기가 없어 이걸 켜면 글이 창 밖으로 넘치므로 적용하지 않음.
- 설정 → 초기화는 메모·방문 상태 등 데이터만 지우므로 위 두 키는 남습니다.

## 확인 방법
1. 시크릿 창으로 사이트를 열면 도움말 창이 바로 열리는지 확인. 닫고 새로고침하면 다시 안 열리는지 확인.
2. 평소 쓰던 브라우저(메모·탭 기록이 있는 곳)로 열면 도움말이 자동으로 안 열리는지 확인.
3. 전체 탭이나 B 열에서 `18+` 부스를 누르면 상세 위에 안내 창이 뜨는지 확인. 창 밖을 눌러 닫고 다른 성인 부스를 누르면 다시 뜨는지, "확인"을 누른 뒤에는 어떤 성인 부스를 눌러도 안 뜨는지 확인.
4. 일반 부스(A 열)는 안내 없이 바로 열리는지 확인.
5. 설정 → 초기화 확인창에 "취소"와 빨간 "삭제" 버튼이 그대로 있는지 확인.
