# kemoket_list 위키

퍼리 행사 부스 목록을 손쉽게 둘러보기 위한 정적 웹사이트의 작업 기록입니다.
처음에는 2026-09-20 도쿄 케모켓(東京流通センター) 행사용으로 만들었고,
2026-10-02부터 **Furst Class**(2026-11-28~29, 엔포드 호텔 청주) 행사용 사이트로 바뀌었습니다.
케모켓용 사이트의 마지막 상태는 `kemoket` 브랜치에 보관되어 있습니다.
