# 부스컷 이미지 폴더

부스컷 이미지를 이 폴더에 **부스 번호.webp** 이름으로 넣으면 사이트의 부스 목록 카드와 부스 상세 창에 자동으로 표시됩니다.

| 부스 번호 | 파일 이름 |
|---|---|
| A01 | `booth-cuts/A01.webp` |
| B12 | `booth-cuts/B12.webp` |
| A37-38 (두 칸 부스) | `booth-cuts/A37-38.webp` |

- 두 칸을 쓰는 부스(A11-12, A37-38, B31-32, C19-20)는 합친 번호 하나로 이름을 붙입니다.
- 부스 번호는 영문 대문자 + 두 자리 숫자, 확장자는 소문자 `.webp` 입니다(배포 서버는 대소문자를 구분합니다).
- 파일이 없으면 "부스컷 준비 중"(시트 I열이 O) 또는 "부스컷 미제출"(I열이 비어 있음) 문구가 대신 보입니다.
- 같은 파일명으로 이미지를 교체할 때는 `sw.js` 의 `CACHE_VERSION` 값을 올려주세요(이미 사이트를 연 사람의 캐시 때문).

## 고화질 부스컷 넣는 방법
원본 파일 이름이 `[A01]부스이름.png` 형식이면 스크립트가 번호를 넣고 webp로 바꿔 줍니다.

```
pip install pillow
python3 tools/make_booth_cuts.py <원본 폴더> --font Pretendard-ExtraBold.otf
```
- 번호는 공식 부스컷처럼 **왼쪽 위 흰 칸**에 `A-1` 형식(Pretendard ExtraBold)으로 들어갑니다. 원본에 빈 흰 칸이 있으면 그 칸에, 칸이 그림으로 채워져 있거나 없으면 같은 자리에 흰 칸 + 검은 테두리를 새로 그립니다.
- 가로 830px보다 큰 원본은 830px로 줄이고, webp 품질 80으로 저장합니다.
- 두 칸 부스는 두 칸 그림이 같으면(A11-12, A37-38) 앞 칸 하나만, 다르면(B31-32, C19-20) 가로로 이어 붙입니다.
- 원본 폴더에 없는 부스의 파일은 건드리지 않습니다.
