# 부스컷 이미지 폴더

부스컷 이미지를 이 폴더에 **부스 번호.jpg** 이름으로 넣으면 사이트의 부스 팝오버/모달 위쪽에 자동으로 표시됩니다.

| 부스 번호 | 파일 이름 |
|---|---|
| A01 | `booth-cuts/A01.jpg` |
| B12 | `booth-cuts/B12.jpg` |
| C05 | `booth-cuts/C05.jpg` |
| A37-38 (두 칸 부스) | `booth-cuts/A37-38.jpg` |

- 두 칸을 쓰는 부스(A11-12, A37-38, B31-32, C19-20)는 합친 번호 하나로 이름을 붙입니다.
- 부스 번호는 시트 A열 그대로(영문 대문자 + 두 자리 숫자)이고, 확장자는 소문자 `.jpg` 입니다. (GitHub Pages는 대소문자를 구분합니다)
- PNG 등 다른 형식이면 JPG로 변환해서 넣어주세요. 용량이 크면 가로 1200px 정도로 줄이는 것을 권장합니다.
- 파일이 없으면 "부스컷 준비 중"(시트 I열이 O) 또는 "부스컷 미제출"(I열이 비어 있음) 문구가 대신 보입니다.
- 이미 사이트를 열어본 사람은 같은 파일명으로 이미지를 교체해도 브라우저 캐시 때문에 예전 이미지가 보일 수 있습니다. 교체할 때는 `sw.js` 의 `CACHE_VERSION` 값을 올려주세요.
